# 两种整体参数配置

本页为新 HB／LH 实例规定完整的参数归属，复用[共同架构](architecture-learning-note.md)、[KV](kv-memory-learning-note.md)和 [SSD](recurrent-memory/ssd-learning-note.md)的函数。只保留 `independent` 与 `shared` 两种主配置；它们是模型绑定的选择，运行中不切换。已存在的教学实例保留各自参数定义。

## 1. 参数、状态与分组

节点参数归节点所有，区域 query 等参数归区域所有。HB 的节点共享组为“层号、D/H 角色、记忆种类、形状”；区域共享组为“层号、区域类型、形状”。区域类型指 D 区、H 区或 mixed 区，形状还包括实际选用的函数和头数。只有同形且同用途的参数共享，不能因两个矩阵大小相等就共用。

LH 以“侧 I/O、层次、角色、记忆种类、形状”代替节点组，以“侧、层次、区域类型、形状”代替区域组；卫星层次为底层深度。不同层的参数不共享。输入投影和任务头属于边界，在两种配置的比较中保持相同绑定。

每节点的 KV 条目、SSD 矩阵、摘要、卷积缓存、时间戳始终私有；共享参数不共享这些状态。区域历史仍是主绑定中的单点。零初态、窗口、位置函数、温度、预算等固定超参数按实例规定，相同数值不计作可训练参数共享。主绑定中的归一化 $\epsilon$、增益和残差尺度也固定。

## 2. 独立配置

`independent` 为每节点分别给定全部有限可训练参数；每区域分别给定 query 及其他区域头。聚合取共同架构的“节点独立”行：$A_v,B_v,e_{v,a}$，同一节点的不同来源类共用 $A_v,B_v$，类别嵌入分别给定。不同节点之间不绑定相等。

KV 的区域基座接口仍可表示完全独立的写入。取

$$
r_a=d,\qquad W_j^{\mathrm{KV}}=0,\qquad
 V_v^{\mathrm{ad}}=I_d,\qquad
 U_v=\begin{bmatrix}W_v^K\\W_v^V\end{bmatrix}.
\tag{1}
$$

零基座和单位矩阵固定，不是待训练的共享权重；任意独立 $K,V$ 矩阵由 $U_v$ 表示。因此不受秩 8 限制，也无需为这一固定因子表示增加冗余训练参数。其余节点矩阵、向量、偏置、卷积抽头和归一化尺度直接独立给定。记忆教材内部已有的同节点共享关系保持，例如同一摘要投影被多处使用时仍是同一参数。

## 3. 分层共享配置

`shared` 给每个节点矩阵用途 $W$ 绑定

$$
\begin{aligned}
W_v&=W^0_{g(v),W}+L_v^W R_v^W,\\
W^0_{g(v),W}&\in\mathbb R^{a\times b},\qquad r_W=\min(r_{\mathrm{ad}},a,b),\\
L_v^W&\in\mathbb R^{a\times r_W},\qquad
R_v^W\in\mathbb R^{r_W\times b}.
\end{aligned}
\tag{2}
$$

默认 $r_{\mathrm{ad}}=8$，尺寸对照可取 4、16，运行中固定。这些是同一 shared 归属的适配宽度，不增加第三种参数配置。$r_W$ 限制私有修正 $L_v^WR_v^W$ 的秩，完整 $W_v$ 仍可满秩；消息宽度与活跃节点数不由它限制。一个共享组内 G 个 $a\times b$ 矩阵的参数量从 $Gab$ 变为 $ab+Gr_W(a+b)$，相应地限制了节点之间的函数差异。

节点保留私有适配器，基座按 §1 的节点组共享。向量和标量按相同节点组共享，唯一固定例外是 cat 局部评分的最终标量偏置逐节点独立。区域参数按区域组完全共享，不附加逐区域适配器。来源嵌入按“节点组、来源类别”共享；不存在的来源类不求值。卷积核按滞后索引的向量处理，不因为实现将其存成二维数组就额外套矩阵适配器。

KV 写入是式 (2) 的特定已有表示，不重复增加适配器：取 $r_a=\min(r_{\mathrm{ad}},d)$，直接使用教材的 $W_j^{\mathrm{KV}}+U_vV_v^{\mathrm{ad}}$。**这个基座按区域组共享**，服从教材每区一个基座的规定。D/H 分区时可各有基座；mixed 区中两角色都用 KV 时共用该区基座，角色差异由私有适配器及其余节点函数表达。不能在同一 mixed 区暗中给同一个 $W_j^{\mathrm{KV}}$ 两个值。KV 查询矩阵 $W^Q_{v,h}$ 则逐数学头分别适配，打包存储不合并适配器。

| 部件 | 参数归属与 shared 的绑定 |
|---|---|
| Agg | $A_v,B_v$ 用式 (2)，$e_{v,a}$ 按组与类别共享；两种配置均采用节点参数接口 |
| KV 写入 | 上述区域基座例外，节点私有 $U_v,V_v^{\mathrm{ad}}$ |
| KV 摘要、查询、读取和输出 | 节点投影用式 (2)；主候选的旋转频率与零距离偏置为固定配置 |
| SSD 投影、摘要与读取 | 节点矩阵用式 (2)；$A^{\log},b^\Delta,D_h$、卷积抽头与偏置、输出 norm 尺度按节点组共享 |
| Describe、当前特征与局部评分 | 所有节点投影和评分矩阵用式 (2)，向量按组共享，最终局部评分偏置私有 |
| 区域 query、区域评分及控制头 | 区域参数按区域组共享；若另选 learned total／threshold，区域头仍按此规则，节点证据编码按节点规则 |
| Full／FFN | 包含 gate/up/down、记忆输出投影等全部节点矩阵，不只共享记忆写入 |
| Next、广播、固定边界 | 无新增可训练参数；输入投影与任务头按共同外部绑定 |

有限参数的形状与合法范围继续服从所选函数。矩阵适配只用于本表所指的实数投影；带约束的门参数保留教材的原始参数化，再在原始参数上绑定共享。未启用的函数不引入闲置参数。

## 4. 规模与通信含义

独立配置的主要参数量为各节点完整参数与各区域头之和。共享配置的矩阵量为

$$
\sum_g\sum_W a_Wb_W+
\sum_v\sum_W r_W(a_W+b_W),
\tag{3}
$$

再加共享向量、私有评分偏置及区域参数；KV 基座按实际区域组计一次。扩宽仍增加私有适配器和状态，不能只用节点数代替参数量。独立配置给每节点更多自由参数；共享配置减少重复大矩阵，并可使同层同角色算子更容易批处理，两者效果均需实测。

共享在推理期可复制权重，使前向继续沿固定消息图通信；精确训练时共享权重的梯度为

$$
\nabla_{W^0_g}\mathcal L
 =\sum_{v:g(v)=g}\nabla_{W_v}\mathcal L.
\tag{4}
$$

若该组跨设备，训练步需要组内梯度归约；可以累计到训练步末再同步，无需每条消息都同步权重。参数复制不能消除这项通信。独立配置去掉跨节点的权重共享归约，消息反传与数据并行仍可能通信。两种配置都不自动保证端到端的局部训练通信。

新 HB 主绑定默认 `shared`，`independent` 是完整对照；不再把跨全部深度共享列为第三个主候选。比较时固定图、局部 K／S／X 和时钟，仅替换本页整组归属，并说明参数量和训练通信的变化；不要求与全部其他轴做笛卡尔积。
