# 带权 KV：实现核对

本文将[局部教材](weighted-kv-sparse-activation-example.md)及其[全连接](weighted-kv-layered-example.md)、[HB-Lattice](weighted-kv-hb-lattice-example.md)组合中的数学性质整理为实现核对项。函数、证明、求解映射和反向目标以教材为准；这里指定需覆盖的情形与证据。训练质量、分工与性能的比较见[训练实验与推进](memos/learning-systems/weighted-kv-experiment-plan.md)。

## 1. 采用范围与比较关系

实现固定上游提交、局部配置、图与时间绑定，并逐项声明已支持的组合。记录浮点类型、数值容差、下溢、裁剪及分段边界的反向约定；采用约束软选择时另记求根终止条件。配置名称与数学对象对应局部教材附录 S.2。

| 比较 | 数学依据 | 保留的对象 |
|---|---|---|
| 同一函数配置的参考递归与实现 | 正典的解码与精化关系、局部教材 §10.1—10.2 | 完整作用结果、逐边／逐端口输出、快照、持久状态和边界消息 |
| 联合求值与逐次求值 | 局部教材 §10.3—10.4 | 实际 P/S/U/F 支持、全部规范值及右边界 |
| 零消息与弱消息 | 性质 1、命题 2、式 (1) 与式 (30) | 对齐后的消息、有效缓存和连续读出投影 |
| 软选择的温度极限与硬选择 | 式 (12)、(14) 与命题 3 的输入、评分条件 | 消息、有效缓存和连续读出投影 |
| 反向实现 | 附录 S.3 的约束求解、S.5 的直接 Attention 及采用的边界约定 | 声明目标的向量—Jacobian 乘积 |

完整状态解码与有效状态投影分别核对。弱消息消失和软硬极限允许原始事件数变化；固定函数配置的精确求值仍保留该函数配置要求的规范记录。有限数值试验提供实现证据，命题的一般结论由正式证明给出。

## 3. 选择、求解与反向

<a id="31-前向"></a>

### 3.1 约束软选择与硬选择的前向

对 quad、bern、ent 的 $\alpha=1,1.5,2$ 及其他已支持的形状参数值，检查每个候选的发送强度上下限、发送强度之和的约束、互补条件与最优性。小规模结果可与独立数值求解或二次族的断点算法比较，记录总和约束残差和解误差。

覆盖空候选、全零发送上限、单有效候选、$M=1$ 及两侧、全部低于阈值、预算上限与总和下限取等号、两界松弛、没有或只有一个满足 $0<c_v<\mu_v$ 的候选。按局部教材 §4.2 核对单点可行集与共同阈值的性质。硬选择覆盖稳定平票次序、零发送上限排除、全低分最高分保留及容量上限。

求根实现核对区间、单调性、终止规则及退化分支。极小正控制量、精确零、浮点下溢和人为裁剪分别记录；bern 与 Shannon 在正温度的全正支持按精确函数解释。额外阈值裁剪构成需要独立声明的前向变更。

对 ent_alpha=1、k=1 且有效发送上限全为 $1$ 的输入，比较直接 softmax 与约束求解的前向及评分反向；覆盖单候选、评分平移、相等评分和很大的评分差。零上限候选不进入归一化。改变任一前提时核对仍求原约束问题，尤其复现局部教材 §7.8 的 $\mu=(0.2,1)$ 算例。数值近似等于 $1$ 的上限不能无条件作为数学上的单位上限。

<a id="32-光滑分支与边界"></a>

### 3.2 约束软选择的反向与边界

反向目标是附录 S.3 的最优解映射，或实现另外声明的有限迭代映射。两者分别比较。光滑点用不跨约束分支的扰动核对评分、上界及适用的温度导数；依次测试总和上下限和松弛分支，再检查 query、key、记忆检索与增益的完整链路。

发送强度之和固定在下限或上限且 $\sum_v a_v>0$ 时，核对加权中心化和上界导数；只有一个未触及上下限的候选时，直接评分导数为零。在 $M<1$ 分支核对局部教材 §8.3 的评分与发送上限 Jacobian。$\sum_v a_v=0$ 时进入饱和或边界分支，避免除零。

在精确断点、$M=1$、总和约束松紧切换、增益截断及支持边界，按已声明的单侧或广义导数核对。普通双侧有限差分只适用于可微点。始终计算内容再乘零与跳过零分支可能有不同边界反向，应分别对照所采用的目标。

低温未触及上下限的区间、极小响应斜率与不同比例的上界需要检查梯度误差。求根残差与反向误差分别报告。硬函数的替代梯度、可训练 ent 形状参数和其他探索机制采用各自定义后的独立检查。

对普通 softmax 情形，核对局部教材 §8.5 的 Jacobian、评分平移方向、单候选零评分导数及 query/key 链路，并与通用隐式反向比较。直接 softmax 求值仍须保留发送上限经 query 的梯度；向零上限坐标增加正上限、达到上限或单候选的边界导数继续按原映射和已声明约定核对。

### 3.3 直接 Attention

selection_mode=direct 按局部教材 §7.9、§8.6 和附录 S.5 求值。归一化权重正比于 $\mu_v\exp(s_v/\tau_{\mathrm{soft}})$，发送强度为 $c_v=\mu_vp_v^{\mathrm{sel}}$；任意合法发送上限均无需约束求解或求根。k、eta、budget_family、ent_alpha 不参与该函数。

| 对象 | 核对内容 |
|---|---|
| 前向与支持 | $0\le c_v\le\mu_v$，$A=C_{\mathrm{eff}}$；有效候选非空时 $0<\sum_vc_v\le\max_v\mu_v$；空候选和全零上限返回零控制及空激活 |
| 归一化与边界 | 评分平移、候选置换、单候选 $c=\mu$；零上限候选无影响，弱候选趋零时其归一化贡献也趋零 |
| 手算 | 等评分下 $\mu=(0.2,1)$ 得 $c=(1/30,5/6)$；$\mu=(1,\varepsilon)$ 得 $c=(1/(1+\varepsilon),\varepsilon^2/(1+\varepsilon))$；所有上限同为 $m>0$ 时 $\sum c=m$ |
| 等值范围 | 有效上限全为 $1$ 时，前向及评分导数等于普通 softmax，也等于 k=1 的约束 Shannon；发送上限导数分别按各自函数核对 |
| 反向 | 正上限处对评分与发送上限做有限差分，核对 §8.6 的 VJP，再检查 query/key、记忆、增益及加权 query 的完整链路 |
| 零上限导数 | 其他上限非零时检查固定评分的右导数；全部上限为零时检查 S.5 的方向导数及声明的实现约定，掩蔽零坐标的自动微分不自动等于该右导数 |
| 数值范围 | 稳定 log-softmax 与显式公式等值；很小的正上限、很大的评分差、下溢及裁剪分别记录 |

direct 不承担约束选择的总和下限，$M\le1$ 时也不要求 $c=\mu$。浮点下溢产生的零值与数学函数的精确支持分别计量。

## 4. 数值连续性与硬化

固定图、参数、离散时间槽、窗口、位置函数与有限切面，从空初态构造输入序列。覆盖弱消息、弱候选、最后一条记忆趋零、长期空档和窗口过期；允许弱槽的裸内容有不同有界极限，比较教材规定的加权投影。

| 情形 | 应比较的性质 |
|---|---|
| 增删零消息；按正发送强度激活与全候选参考计算 | 性质 1 的数值投影相同，分别保留各自原始记录 |
| 温度固定或趋向正值 | 命题 2 的投影连续性，覆盖约束软选择、direct 及逐区域混合，含候选消失与正时延反馈 |
| 单位输入，硬运行满足间隔条件 | 式 (12) 与式 (14) 的命题 3 软硬投影收敛；核对的是硬运行各次选择 |
| 固定每个 $\mu_v\in\{0,1\}$ 与分离评分 | quad／ent 的 $\alpha>1$ 可在有限正温精确达到硬选择的发送强度 |
| 平票、阈值临界、固定介于零和一之间的发送上限 | 复现局部教材 §9.8 的边界例子，不套用超出前提的软硬断言 |

使用固定稠密、稀疏、多区域图及有限正时延反馈图覆盖拓扑范围。单位强度指载荷 $(1,z)$，内容向量按有界条件取值。发送强度收敛与激活数收敛分别核对，尤其保留 bern 与 Shannon 在正温度的支持性质。

direct 的连续性另外覆盖所有发送上限同时趋零的情形。其固定正温性质不构成对式 (14) 的硬化结论。
