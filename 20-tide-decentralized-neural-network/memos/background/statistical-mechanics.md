# 统计力学与信息动力学：保留问题，不预设物理结论

本页由 Git `133d638` 的 `tide-statistical-mechanics-and-information-dynamics.md` 重写。原问题入口是 [[30-technical-notes/hilbert-sixth-problem-and-ai-entropy|希尔伯特第六问题与 AI 熵类比]]。它不向核心教材导入物理公理，也不主张 Tide 已有 kinetic limit 或耗散结构定理。

## 1. 值得保留的三个问题

1. 微观历史被压缩后，哪些差异仍会影响未来可观察行为？
2. 共同祖先、路径重汇聚和私有记忆怎样影响表示、梯度与路由？
3. 图规模或传播尺度增长时，是否存在有用的宏观统计描述？

第一项已有清楚的语义问题形式，见 [来源、聚合与读出](../mathematics/provenance-and-readout.md)。第二项可先做有限尺度测量。第三项需要额外的随机模型、尺度和收敛概念，不能由一张局部图直接推出。

## 2. 不同“环”与不同“历史”

物理碰撞展开中的 diagram 用来组织粒子相关性和估计；Tide 事件图记录函数作用的依赖。二者都使用图，不意味着顶点、边、概率结构或定理可以互换。

尤其区分：空间图带正时延的环、展开事件图的有向环、同一祖先经过两条路径重汇聚的 diamond、自回归输出影响未来输入。Residual 的前向 identity edge 不是同一事件上的自环。

KV 是具体 attention 契约的持久状态，不保存完整 residual、FFN 激活和所有路径。把所需 KV 包含进状态后，decode 可写成确定的一步状态转移。SSM 的固定维度状态对自己的递推是精确的，却不自动成为 Transformer 的无损摘要。

## 3. 一个候选经验测度

设一族有限图 $G_N=(V_N,E_N)$ 的节点按类型 $r$ 分类。对某个非空类型集合 $V_{N,r}$，节点在时间 $\theta$ 有神经状态 $q_v$、控制描述 $c_v$ 和激活指示 $a_v$。可以定义

$$
\mu_{N,r}^{\theta}
=\frac1{|V_{N,r}|}\sum_{v\in V_{N,r}}
\delta_{(q_v,c_v,a_v)}.
$$

这是一个经验分布，不是自动成立的极限定理。若进一步研究 $N\to\infty$，至少须说明：图怎样增长，状态空间及度量是什么，随机性来自数据/初始化还是显式随机机制，$\theta$ 与训练步怎样区分，以及要证明何种收敛或误差界。

层级图中的 backbone、receiver 与输出节点可能分布完全不同，不应无条件假设节点可交换。局部有界度也不自动产生独立性；共同祖先和长期状态可能维持强相关。

## 4. 路径相关性先测什么

可以分别记录：

- 每个 merge 的有效来源数、共同祖先比例及来源集合重叠。
- 分支 delta 的范数、夹角、抵消程度。
- 不同来源对输出/loss 的梯度贡献及 checkpoint 间变化。
- Receive/Update/Read/Emit 覆盖、状态写到读的时间差。
- BO 与 SD 在匹配结构和计算预算下的状态使用差异。

路径边数、实际消息 hop 数、昂贵模块数、私有状态写到读的时间差是不同量。仅统计无向 cycle 数或 attention 非零项数量，忽略了权重、符号、非线性和后续读出，不能直接解释训练或生成质量。

这些是诊断量；相关性不是因果归因，且不替代 chunk 正确性验证。

## 5. 路由熵只回答一个有限问题

在明确统计窗口中，节点激活次数为 $n_v$，总数非零时令

$$
p_v=\frac{n_v}{\sum_un_u},\qquad
H_{\mathrm{route}}=-\sum_{v:p_v>0}p_v\log p_v.
$$

较高路由熵通常表示激活更均匀。它不自动表示内容选择有效、节点专门化、梯度覆盖或质量提高。

可联合比较负载偏斜、route 与任务特征的互信息、route churn、有效梯度、state knockout 和最终质量。互信息也要注明随机变量与采样分布，不能凭可视化上似乎形成簇就断言。

| 名称 | 对象 |
| --- | --- |
| 热力学熵 | 物理状态及能量交换 |
| Boltzmann/kinetic entropy | 粒子分布函数的泛函 |
| Token entropy | 模型预测分布的不确定性 |
| Route entropy | 激活占用分布 |
| 表示协方差/谱 | hidden 的几何统计 |
| 语义压缩的信息损失 | 抽象映射合并了哪些未来可区分状态 |
| 任务质量 | 明确任务上的 loss、accuracy 或 verifier 结果 |

这些量没有无条件等价关系。不能用“熵高/低”统一代替均衡、正确、丰富或高质量。

## 6. 何时才值得研究宏观物理模型

讨论耗散结构至少需明确系统边界、状态过程、随机性、通量、熵或 Lyapunov 泛函、序参量及长期行为。只有选择了具体模型，才能问某个稳态或分岔是否存在。

“LayerNorm 是恒温器”“权重储存负熵”“采样把熵排出系统”在当前都只是类比。计算硬件确实耗电散热，但这一事实几乎适用于所有算法，不解释 Tide 的特殊优势。

较合适的研究顺序是：先在固定模型上得到可复现的有限尺度统计，再定义最小随机模型，最后根据其结构选择 interacting-particle、mean-field、local weak limit 或其他工具。没有理由预先规定最终一定得到 Boltzmann 方程。

## 7. 与其他笔记线的接口

Control Feedback 中的外部观测可以研究信息增益和修复收益；Memory 中的摘要可以研究未来可观察信息是否保留。它们与本页共享提问方式，但各自有不同状态、事件和输出契约。

Tide 的确定性语义、node batch 条件及自适应下界不由上述物理类比改变。若统计指标发现有用信号，实验平台负责记录数据、测量和反事实，上游只在得到明确对象与证明后新增数学结论。
