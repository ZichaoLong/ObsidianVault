# 脑科学给数字模型的启发，以及它不能证明的事

脑网络的调查正文及参考文献见 [人脑信号传播调查](neuroscience-survey.md)。本页只整理与局部图模型相关的设计问题，避免把解剖事实、解释模型和数字架构假设写成同一层结论。来源为 Git `133d638` 的架构旧文第三部分 §14。

## 1. “稀疏”至少有四种含义

结构稀疏是连接数量相对稀少；群体稀疏是某时刻部分神经元活动更强；时间稀疏是单个神经元只在部分时间放电；功能稀疏是某些群体对特定任务贡献更显著。

它们不等于一个全局 Top-K router 把完整模块从零切到一。神经元有阈值，但亚阈值膜电位、局部突触及背景活动仍可能变化；轴突的解剖去向相对稳定。大尺度任务图上的“未激活”也不表示整个脑区没有接收输入或更新状态。

这给出一种数字模型假设：分开接收/状态更新与昂贵读出/发送，并比较 BO 与 SD。但脑科学不决定数字算子的最优状态规则；两种模式应按教材分别定义、按实验比较。

## 2. 微观变化与宏观功能

脑科学中的 representational drift 指微观活动或调谐变化而行为可能保持相对稳定。群体冗余、下游适应、稳态可塑性及不同时间尺度可能共同参与，不能简化成一个已被证明的“脑内 quotient theorem”。

数字模型可以据此追问：不同 active set 是否产生接近的固定接口表示？限制单节点 residual、提高重叠、缩短控制寿命是否有帮助？这些问题可以通过明确的扰动界和实验回答，见 [训练风险](../learning-systems/learning-risks-and-diagnostics.md)。

候选节点从 16 增至 4096，不会自动缩小 Top-1 切换两个完整函数的差异。脑的微观小贡献不能直接外推成“大量独立大模块随意切换也会平滑”。

## 3. 生物信用分配仍是开放问题

可参考的机制包括感觉预测误差、小脑误差信号、基底节奖励学习、eligibility trace、海马/皮层重放，以及神经调质对可塑性的影响。它们不组成一个已知等价于全脑精确 backprop 的算法。

数字模型可以研究局部辅助 loss、teacher representation matching、训练数据 replay 或受控 shadow 分支。训练重放不一定改变推理函数；推理中主动重演内部轨迹则是另一种状态与依赖结构。

“人脑能长期学习”不能证明某个随机初始化、长控制链的图模型只靠最终语言模型 loss 就能训练好。生物体还拥有进化、发育、身体闭环和多种先验。

## 4. 多条通路、汇合与时间尺度

真实脑网络没有唯一全局 residual backbone，但存在相对稳定的感觉/运动通路、多级 hub、丘脑中继和多种重汇聚。可以由此提出多个局部 backbone、有限生命周期分支和层级接口的数字构型；固定加法 merge 是数字设计，并非声称脑内使用同一个算子。

快速反应与较慢上下文处理提示了两种不同问题：哪些内部结果决定当前输出，哪些只改变未来处理？在 Tide 中必须用端口、正时延和读出规则回答，不能用墙钟“没赶上”定义数学结果。

局部恢复/阈值也可以启发 selector-history。用统一逻辑时间保存上次值和时间、在下次读取时算出衰减，是一个简洁数字实例，见 [Selector 与局部记忆](../architecture/selector-and-memory.md)。不需要为了模拟生物连续活动而让每个空纤维都生成事件。

## 5. 可证伪的提问方式

| 生物启发 | 数字模型中可研究的问题 | 不能自动推出 |
| --- | --- | --- |
| 持续背景状态与稀疏放电 | BO 是否改善以后读取到的私有记忆？ | 写入覆盖等于有效梯度 |
| 局部连接与长程通路并存 | 有界局部汇合加少量层级通路如何权衡传播与通信？ | 图邻接等于物理局部性 |
| 群体冗余 | 小 residual 与 active overlap 是否降低扰动？ | 节点越多越稳定 |
| 多尺度恢复和调制 | history、阈值、时间衰减何时有收益？ | 越接近神经元越容易训练 |
| 重放与局部教学 | replay/辅助 loss 是否改善延迟信用？ | 生物学习已经解决精确全局信用分配 |

人类语言理解也没有提供 Transformer 式高性能 prefill 的证明。机器的矩阵乘、scan、packed kernel 是独立的工程能力，必须根据数字模型的函数依赖分析。
