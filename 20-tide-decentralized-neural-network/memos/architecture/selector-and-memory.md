# Selector 与局部记忆：机制动机与设计取舍

本文分析带权 KV 候选的表达能力、梯度与成本，并区分数学结论、设计直觉和外部实验依据。函数及证明以[局部教材](../../weighted-kv-sparse-activation-example.md)为准；具体对照和推进依据见[训练实验与推进](../learning-systems/weighted-kv-experiment-plan.md)，程序正确性见[实现核对](../../weighted-kv-implementation-checks.md)。

## 1. 稀疏、反馈与分工

局部教材第 4、8 节分别说明发送强度、激活集合与选择函数的导数。quad 与 ent 的 $\alpha>1$ 能在正温度产生精确零；发送强度未触及上下限时可以响应任务梯度；有用分工则要求节点的差异对任务形成互补贡献。这些性质为研究提供不同的判断依据。

固定发送强度之和时，评分反馈比较候选的边际影响。ind 的独立描述仍经预算乘子形成竞争，因而具备学习条件分配的途径。未触及上下限的候选只有一个、可行集为单点，或各候选边际影响相同，都可能使直接评分梯度为零。丰富评分器能增加可用信息，其收益仍依赖分配层和后续任务提供反馈。

私有状态与参数为分工提供表达空间。相同输入、同参数与同历史也可保持数值对称；激活次数均衡只描述使用分布。节点承担什么任务、拥有何种互补记忆，需要自己的实验依据。

## 2. 信息来源与参数共享

| 设计轴 | 有利特性与动机 | 限制与风险 |
|---|---|---|
| 区域共享聚合 | 使用共同特征空间，减少参数；来源嵌入仍能区分来源 | 压缩后已丢失的信息通常无法由节点适配恢复 |
| 节点／来源独立聚合 | 在压缩前形成不同视角，更容易表达不同任务所需的信息 | 增加所有候选的准备与参数；私有部分需要足够输入和梯度覆盖 |
| 共享 KV 基座与私有适配 | 共享部分汇集训练信号，私有部分保留分化空间 | 适配秩限制差异；两因子同时零初始化时初始乘积梯度为零 |
| 时间摘要 sum | 按时间和权重汇集，成本较低，历史条目可广泛参与描述 | 少量相关证据可能被稀释，当前内容在汇集以后才参与判断 |
| 内容检索 qry | 当前输入先查询私有记忆，能够表达任务相关的证据检索 | 候选均支付检索成本；注意力集中可使部分条目长期缺少反馈 |
| 拼接评分 cat | 单隐藏层网络包含内容、统计量及交互项，提供较小基线 | 可能利用接收频率或记忆长度等统计捷径，特征尺度与内容使用需辨明 |
| 分组匹配 match | 分组非线性编码与归一化，显式内容—记忆匹配及残差 | 匹配相似度到执行价值仍需学习；归一化可能弱化幅值信息，乘性交互增加优化复杂性 |
| 独立区域评分 ind | 描述较小，预算仍提供竞争，依赖关系较容易分析 | 各候选先压成标量，跨候选当前内容的关系表达有限 |
| 区域 Attention att | 共享 query 比较私有记忆；正上界的零发送强度候选可经 query 影响其他评分 | 单 query 汇集有压缩限制；反馈更耦合，仍缺少未执行 Full 的直接反事实价值 |

memory、local_score、region_score 是独立设计轴。cat 已经含非线性与内容—记忆逐坐标交互；match 通过分组编码、归一化与显式点积给出进一步的结构偏好。局部匹配不要求启用区域 Attention，内容检索也可接独立评分。

参数共享与数值复用具有各自条件。来源类别、载荷与出现次数相同，且函数相同，才可共同求值；HB 的不同邻域即使共享参数，通常仍产生不同聚合。全连接实例同层面对相同来源载荷，更依赖私有参数和历史内容形成差异。HB 的邻域已提供不同视角，同时带来上游路径暴露不均的风险。

区域 query 按发送上限加权，具有弱候选消失性质。扩大区域会增加控制信息范围；多个局部区域则分别形成 query。区域匹配的单 query 对候选数是线性工作量，是否值得采用应连同其影响的下游工作判断。

## 3. 预算正则与梯度取舍

正则的响应、恢复关系与导数见局部教材第 8 节。下表概括其研究含义。

| 候选 | 有利特性 | 风险与成本 |
|---|---|---|
| quad | 正温度精确稀疏；尚未触及上下限的小分量仍有 $1/\tau$ 的响应斜率；便于建立基线 | 严格零／上界饱和后直接评分反馈消失；低温时上下限之间的响应较陡 |
| ent，$1<\alpha<2$ | 同样精确稀疏，接近零时响应更平缓 | 小发送强度的响应斜率 $c^{2-\alpha}/\tau$ 较小，微弱候选的恢复反馈可能更弱 |
| bern | $M>1$ 时有效候选的发送强度保持在上下限之间，扩大直接反馈覆盖机会 | 正温度执行所有有效 Full；极端占用比例下梯度仍可很小 |
| ent，$\alpha=1$ | Shannon 型分配与广泛正支持，适合比较反馈覆盖的作用 | 正温度无精确零，可上界饱和；小发送强度也可能只有很弱的反馈 |

ent 的 $\alpha=2$ 与 quad 具有局部教材式 (29) 的阈值移位关系。普通 softmax 是单纯形特例，适用于一次单位发送强度的分配；本文的软选择还限制每个候选的发送强度，并允许强度之和在规定区间内取值。求解只需一维协调，反向由最优性条件获得，精确定义见附录 S.3。

同一样本上的饱和可稳定已有分配并省去工作。其他输入和历史可能使节点重新进入未触及上下限的区间，也可能使早期错误分配长期保持。正发送强度、非零导数和有效任务更新的范围需要分别判断。数据多样性提供恢复机会的直觉，其实际覆盖由实验确认。

低温同时扩大严格饱和区域，并使剩余过渡区的斜率可能较大。固定且分离的评分可完全饱和，跨样本接近边界的评分则可能产生尖峰。归一化、attention logit、长期 Jacobian 乘积、求解误差和成本代理的近零斜率也会影响稳定性。前向连续性提供值的控制，优化稳定性还有这些独立因素。

## 4. 总和下限与弱接收增益

### 4.1 已定义的下限

局部教材固定 $b_\Sigma(\mu)=\min(1,\sum_v\mu_v)$。它既保证有效候选非空时有发送，也给出区域发送强度保障；在局部教材 §4.2 的单点可行集情形，评分对本次分配的导数为零；这一性质由约束决定。

在两个现有单位输入组合中，原下限都维持每区 $M\ge1$；全连接更逐节点保持 $\mu=1$。HB 允许单节点弱接收，区域的发送上限之和仍可至少为 $1$。局部分配余量与未触及上下限的候选应结合整个区域理解。

### 4.2 待绑定的下限候选

一个研究候选是在同一可行域定义中将下限改为

$$
b_{\max}(\mu)=\max_v\mu_v,\qquad \max\varnothing=0.
$$

它连续，关于无穷范数为 $1$-Lipschitz；非零上界族上满足 $0<b_{\max}\le b_\Sigma$，当每个 $\mu_v\in\{0,1\}$ 且至少一个为 $1$ 时，两者都为 $1$。这些事实为沿用可行恢复列和硬运行归纳提供条件。纳入局部函数族时，应补齐该候选的连续性、硬化与反向定义，再建立独立配置；现有教材仍绑定 $b_\Sigma$。

| 下限 | 潜在收益 | 代价与边界 |
|---|---|---|
| $b_\Sigma$ | 更强的区域发送强度保障，低总量时保留全部弱候选 | $M\le1$ 时分配被固定 |
| $b_{\max}$ | 多个弱候选之间可减小部分候选的发送强度 | 需重新检验区域发送强度之和至少为 $1$ 的传播性质；放松可行域仍可能得到饱和解或只有一个未触及上下限的候选 |

唯一最大上界处，$b_{\max}$ 的直接导数集中在该坐标；平票处需声明广义或单侧导数。上界还可通过约束、正则及区域 query 影响选择，这些通路继续存在。最大值的不可微点本身不表示数值发散。

固定 $\mu=(0.9,0.8),t=(-2,-1),k=1$ 时，原下限的软零温极限为 $(0.2,0.8)$，最大上界下限的极限为 $(0.1,0.8)$，原硬函数为 $(0,0.8)$。这个例子中，改变下限后，软选择的零温极限仍与硬选择不同。单位输入的整网问题依赖随温度变化的上界及发送上限为零或一的硬运行。

另一个提议 $b=\min(1,M/2)$ 连单位单候选的端点也会改变：$\mu=1,t=-1,k=1$ 时 quad 的软解对任意正温度均为 $1/2$，原硬函数为 $1$。采用它需重新选择硬目标及传播性质。

### 4.3 有界发送增益

固定 $\gamma>1$ 已允许弱接收放大；context 进一步依据当前内容、记忆和统计量调整增益。局部教材 §9.4 证明固定有限路径上的零边界连续性，并给出弱信号恢复到单位强度的例子。写入仍按实际接收权重，记忆唤醒与新证据强度分别表达。

增益有机会提供评分分配以外的学习通路，也可能放大无效信息、增加后续工作，并更早触及上界截断。全连接单位输入下增益没有前向差异；HB 的弱接收为这一候选提供可辨别的场景。

## 5. 固定拓扑与全图成本

局部教材的单位输入硬化定理适用于固定有限正时延图及有限切面，评分条件核对硬运行。空间边在不同输入和历史中继续可用；永久删边改变另一个架构对象。

接收候选已经支付 Agg、写入与 Read，零发送强度首先省去 Full 和发送。下游节点若失去全部输入，还省去整次准备与状态更新。全连接实例始终覆盖下一层全部节点；HB 按激活者邻域并集确定候选，父邻域重叠会减少独占覆盖。

更强的 selector 可能以更多当前准备换来更少或更有用的后续计算，收益取决于出度、重叠、输入注入和任务需求。节点宽度、激活数与准备成本占比都只是部分信息。全部区域采用 bern 或 Shannon 时，当前 HB 的正温度运行覆盖全图节点；精确稀疏族才可通过零发送强度减少该覆盖。

局部教材附录 S.4 和实例给出工作量表达式；实际训练、prefill、decode 的质量与成本在实验文档中比较。

## 6. 私有状态与未来信用

BO 与默认 Next 保留当前候选的接收更新，增加未来可读的信息。未来读取、截断反向及上游输入覆盖决定这些写入获得何种反馈。未执行的 Full 没有该步直接反事实读出；教师、shadow 分支或辅助目标需要额外信息与计算。

保留、衰减、选后清理与选择历史分别定义状态行为。恢复惩罚或使用次数历史可改变以后选择，也可能抑制有用节点；推理中采用这些量时，须把它们纳入状态、更新与继续关系。

对无输入时只衰减、不产生自主事件的状态，可保存值 $z$ 与写入时刻 $s$，在 $\theta$ 读取 $\Phi_{\theta-s}(z)$，其中 $\Phi_0=\operatorname{id}$、$\Phi_{a+b}=\Phi_b\circ\Phi_a$。例如 $\Phi_\Delta(z)=\lambda^\Delta z$、$0<\lambda\le1$。阈值、重置与选择加入后的连续性和联合求值需按完整函数判断。

区域历史按模型序列保存。Full 读取既定快照；若下一状态要依赖本次 Full 输出，需重新给出依赖与继续语义。缓存回收、神经状态清理和区域历史更新分别对应自己的对象。

## 7. 外部证据与适用范围

| 来源 | 研究结果 | 对本设计的启发与边界 |
|---|---|---|
| [Martins & Astudillo, 2016，Sparsemax](https://proceedings.mlr.press/v48/martins16.html) | 给出稀疏映射、Jacobian，以及多标签分类与自然语言推断实验 | 支持精确稀疏连续映射可训练；未验证私有状态与长路径路由 |
| [Peters et al., 2019，Sparse Sequence-to-Sequence Models](https://aclanthology.org/P19-1146/) | 定义连接 softmax 与 sparsemax 的 entmax，在形态变化与机器翻译任务中报告收益 | 支持比较正则形状；每个候选的发送上限与总和区间由本文自己的定义处理 |
| [Correia et al., 2019，Adaptively Sparse Transformers](https://aclanthology.org/D19-1223/) | 学习不同头的稀疏程度并观察不同注意力模式 | 支持逐模块稀疏差异的研究；当前局部族使用固定 $\alpha$ |
| [Blondel et al., 2020，Fenchel–Young Losses](https://www.jmlr.org/papers/v21/19-021.html) | 正则化预测与配套损失的统一分析 | 可指导有目标的辅助评分；监督或教师目标需另外提供 |
| [Amos & Kolter, 2017，OptNet](https://proceedings.mlr.press/v70/amos17a.html) | 通过最优性条件对优化层隐式微分 | 支持优化层的反向方法；本文标量求根和导数由自身目标推导 |
| [Jang et al., 2017，Gumbel-Softmax](https://arxiv.org/abs/1611.01144) | 低温更接近离散采样，同时提高梯度方差；采用降至非零温度的方案 | 提供连续松弛与温度取舍证据；随机单纯形采样与本文确定性预算不同 |
| [Maddison et al., 2017，Concrete](https://arxiv.org/abs/1611.00712) | 连续松弛可优化离散随机图；作者在所做实验中未发现退火或自动调温很重要 | 支持保留固定正温对照，避免把退火设为普遍必需 |
| [Hazimeh et al., 2021，DSelect-k](https://arxiv.org/abs/2106.03760) | 平滑稀疏门控在所测多任务问题中具有竞争力；强调避免初始饱和造成零梯度 | 支持检验早期反馈与硬化的取舍；二进制编码和正则机制不同 |
| [Fedus et al., Switch Transformers](https://arxiv.org/abs/2101.03961) | Top-1 专家选择可有效训练，采用选择性高精度、初始化与辅助机制 | 提供硬成员选择的正面证据；其选中 softmax 权重与辅助信号不同于本文硬 $c=\mu$ |
| [Zoph et al., 2022，ST-MoE](https://arxiv.org/abs/2202.08906) | router z-loss 改善稳定性；更紧更新裁剪及部分噪声方案存在质量代价 | 稳定性干预需同时评价质量，具体损失与模型条件不能直接移植结论 |

这些证据支持开展候选比较。Tide 的长期私有状态、广播邻域和跨层覆盖仍需自身结果；数学保证、外部任务结果与研究假设分别维护。机制历史见 [LH 历史](../history/lh-history.md)与[脑科学启发](../background/neuroscience-model-ideas.md)。
