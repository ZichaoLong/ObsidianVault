# Selector 与局部记忆：机制动机与设计风险

本页讨论 selector 和局部记忆的待验证动机，不另立节点语义。候选、描述量、区域历史和状态作用以 [TimedDAG 教材](../../timed-dag-region-selector-learning-note.md) 已定义的对象为准；训练观测与对照方法见 [学习风险与诊断](../learning-systems/learning-risks-and-diagnostics.md)。这里保留机制假设，不把它们写成已证明的性能或收敛结论。旧架构材料的主要来源是 Git `133d638` 第三部分 §4—8、§14.7。

## 1. 当前内容与累积证据

selector 是根据当前可读描述量和区域选择历史，确定候选节点中本次要激活的集合的函数；路由是输入沿图中不同节点传播的路径选择。一个常见动机是同时保留弱而持续的信号，并抑制噪声、短期重复激活和历史优势固化。

设本次区域选择的有限完整候选集为 \(C\)，容量为正整数 \(K\)。对每个 \(v\in C\)，令 \(s_v,u_v,r_v,b_v\in\mathbb R\) 分别表示内容评分、累积证据、恢复惩罚和相对阈值偏置；令 \(n_v\in\mathbb N\) 表示过去的激活次数。系数 \(\alpha_v,\mu_v,\nu_v\) 为非负实数。一个具体评分函数是

$$
\ell_v
 =s_v+\alpha_vu_v-\mu_vr_v
 -\nu_vn_v-b_v .
\tag{1}
$$

所有坐标在选择前确定。selector 按 \(\ell_v\) 的降序取 \(\min(K,|C|)\) 个节点，并以固定节点序打破并列。这里的 \(b_v\) 是相对偏置；即使所有分数为负，只要候选非空仍按容量选取，除非另行把“空选择”纳入正式控制规则。也可以只把历史量用于同分时的排序，或先按内容缩小候选集；这些是不同的 selector，而不是同一公式的隐含实现。

选择完成后，selector-history 可以减少 \(u_v\)、增加 \(r_v\) 或递增 \(n_v\)。这些坐标只服务于之后的选择时，它们属于区域历史，不是节点之间共享的神经状态。连续选择中 active set 或节点身份改变的频率称为 route churn；长期未被选中的节点称为饥饿节点。二者和任务质量、状态读取一起评估，不能只看次数是否均衡。

## 2. 恢复、次数与阈值的不同动机

| 机制 | 想改善的现象 | 主要代价或风险 |
| --- | --- | --- |
| 恢复惩罚 | 短时间内反复激活同一节点 | 可能阻碍持续有用的节点 |
| 激活次数项 | 长期饥饿或容量偏斜 | 可能牺牲内容适配 |
| 阈值调整 | 校准不同节点的选择率 | 适应过快或过慢 |
| 仅在近似同分时用历史 | 保留内容信号并减少任意轮换 | 原本较弱的节点仍可能长期饥饿 |

selector-history 应按模型序列保存；设备负载、队列长度和 batch 同伴属于物理调度记录，不能悄悄成为跨请求的模型证据。若模型确实要让负载影响选择，就把它定义为该序列的显式历史坐标，并在语义和训练诊断中记录。

## 3. 保留、衰减与清理记忆

局部记忆的三个动作应分开描述：

| 动作 | 数学含义 | 需要观察的风险 |
| --- | --- | --- |
| 保留 | 下一状态继续包含本次候选更新 | 写入可能永远不被读出 |
| 衰减 | 读取时按逻辑时间解释旧坐标 | 长空档导致信息过快或过慢消失 |
| 选后清理 | 下一持久状态按选择结果置零或删去部分内容 | 清理可能切断长期信用 |

若只需让空档中的值逐渐变弱，可保存值 \(z\) 与上次保留时间 \(s\)，在逻辑时间 \(\theta\) 读取时定义

$$
z_{\mathrm{eff}}(\theta)=\Phi_{\theta-s}(z),
\qquad
\Phi_0=\operatorname{id},
\qquad
\Phi_{a+b}=\Phi_b\circ\Phi_a .
\tag{2}
$$

例如 \(\Phi_\Delta(z)=\lambda^\Delta z\)，\(0<\lambda\le1\)。节点在时间 \(2\) 保存值 \(8\)，到时间 \(5\) 才再次收到输入时，读取值为 \(8\lambda^3\)；中间不需要调用节点。该表示适用于没有自主输出或无输入激活的衰减。若空档本身产生新事件，就需要改变图的事件语义。

衰减使用统一逻辑时间，而不是墙钟等待时间；其保存、读取和选后清理的正式位置见 [TimedDAG §7.9](../../timed-dag-region-selector-learning-note.md#79-按逻辑时间衰减使用以后清空)。selector-history 的恢复量可以采用同样的惰性解码，但不能因此推出带阈值、reset 和 Top-K 的整个控制器一定能廉价地 parallel scan。

一次激活还可能涉及三种“清理”：回收不再读取的临时 inbox、改变本次作用之后可见的神经状态、更新 selector-history。沿用 TimedDAG 教材已经定义的 `Next`，默认核心语义可以依据本次已知输入和选择结果确定清理；本次 `Full` 应读取选择时形成的不可变快照，不能被随后清理改写。若下一状态要依赖 `Full` 输出，必须重新定义事件依赖和 continuation，不能沿用这里的控制先行假设。

### 3.1 接收驱动的带权 KV 特例

[带权 KV 与稀疏 Full](../../weighted-kv-sparse-activation-example.md) 把上述分工写成完整数学实例。它用 BO 与默认 Next 保留全部候选的接收更新：先把输入聚合为归一化内容与独立强度，按接收强度追加一条 KV，再由廉价 Read 读取候选记忆供区域选择。selector 用带上界的预算投影分配发送门控，整个 Full 内容受门控；门控已受接收强度约束，不再把两者额外相乘。KV 的写入与本节点是否激活分开。

即使 selector 的排序、归一化算法固定，节点仍可学习生成描述量。私有状态让描述量表达“本节点已经记住什么、当前输入是否值得进一步计算”，是额外的条件信息；它是否有用取决于状态质量、Read 成本及任务反馈。若控制量通过可微发送权重影响 loss，就可能训练这些描述量；单独保留一个硬索引并不提供换选节点的普通梯度。

存在但强度为零的消息仍然产生候选，缺席消息则不产生候选。特例用可用记忆系数处理最后一条 KV 的消失，使单位记忆仍返回完整 value；发送门控的上界则使零强度候选不占选择预算。只把普通 Attention 的 value 乘零，或只门控 Full 的残差增量，都不足以得到这些性质。软 Settle 规格仍全选，零门控 Full 走廉价分支；硬规格再缩小正式容量。Graph/TimedDAG 还可以直接省去零门控事件。连续性结论区分固定正平滑参数与单位输入、严格分数间隔下的硬端点，不将质量预算误当成支持数量。

这组局部公式可共享于三类图；节点级时间批大小还取决于图结构、输入封闭证据与精确批量契约。特例中的 [执行基座映射](../../weighted-kv-sparse-activation-example.md#7-公共执行与等价性验证基座的映射) 区分已有通用调度能力与尚需实现的局部模块；[退火实验](../learning-systems/learning-risks-and-diagnostics.md#61-带权-kv-特例的退火实验) 则单独讨论训练信号与实际省计算。

## 4. 怎样判断机制是否起作用

至少要分别观察四件事：内容是否仍能决定选择；写入的状态是否后来被读取；恢复或次数项是否减少了无意义的重复激活；额外历史是否增加了学习负担。建议做以下机制对照：关闭累积证据、恢复惩罚和次数项；分别比较保持、衰减和清理；记录 route churn、饥饿、状态写入到读出的延迟、选择边界裕量和任务质量。

对照必须保持拓扑、参数规模、状态维度和数据暴露尽量一致，并说明是否重新训练。路由分布改变时，清零某个机制后的退化不能直接解释为该机制的收益。详细的语义一致性、梯度覆盖和成本账本见 [学习风险与诊断](../learning-systems/learning-risks-and-diagnostics.md)；具体硬件和 profiling 由实验仓库维护。
