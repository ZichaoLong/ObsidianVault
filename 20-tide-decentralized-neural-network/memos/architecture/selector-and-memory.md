# Selector 与局部记忆：机制动机与设计风险

本页讨论聚合、记忆读取和区域选择的设计取舍。共同对象沿用 [TimedDAG 教材](../../timed-dag-region-selector-learning-note.md)；具体函数、连续性证明与实现要求见 [[weighted-kv-sparse-activation-example|带权 KV 局部教材]]。本页区分数学性质、外部实验结果与 Tide 的待验证假设，观测方法见 [学习风险与诊断](../learning-systems/learning-risks-and-diagnostics.md)。

## 1. 聚合共享与节点分工

接收聚合决定节点在写入前保留哪些信息。区域共享投影让节点使用共同特征空间，减少参数；来源嵌入进入非线性后仍能区分来源。节点独立或来源独立的投影允许在压缩前提取不同信息，代价是更多参数和准备工作。聚合后的适配一般无法恢复已丢失的信息。

相同参数可以处理不同邻域，因而得到不同内容与历史。HB 的稀疏连接本身已提供分工条件；私有 KV 适配器、Read 和 Full 参数再提供其他差异。全连接基线的同一区域收到相同输入，更依赖参数、历史及学习过程形成差异。独立投影是否更好，应分别测量分工、质量和总成本。

参数共享与计算复用具有不同条件。只有来源类别、载荷及其出现次数相同，并且聚合函数相同，才可复用聚合结果；KV 基座也只在输入相同时复用数值。相同参数面对不同邻域时，通常仍要进行不同的聚合和投影。

## 2. 私有记忆读取与区域信息共享

局部教材将记忆描述和评分分开选择：

| 记忆描述 | 独立评分 | 区域 Attention 评分 |
|---|---|---|
| 时间摘要 | 当前内容与短长期摘要压成节点标量 | 各节点内容汇成共享 query，与各自摘要 key 匹配 |
| 内容检索 | 当前内容先查询私有 KV，再形成节点标量 | 查询私有 KV 的结果形成 key，与区域 query 匹配 |

时间摘要按时间与写入权重汇集，后续才与当前内容交互。内容检索在读取时就依据 query 选取记忆，更能表达“当前输入在本节点记忆中找到什么”，但可能增加 KV 读取、投影和反向保存成本。它是否需要接近 Full 的宽度，由实验判断。

独立评分的 Read 返回发送上界 $\mu_v$ 和标量 $s_v^{\mathrm{loc}}$；该标量已经读取当前内容和私有记忆。区域 Attention 则保留更丰富的当前内容特征和记忆 key，由 SelStep 建立区域共同判断。一个共享 query 与候选 keys 的匹配对候选数线性，并不要求候选两两交互。其成本与各节点独立 MLP 的比较取决于宽度和参数化。

共享 query 使用 $\mu_v$ 加权，确保零上界候选不改变其他节点的评分，弱候选的影响也随之消失。每个区域只汇集自己的完整候选；图中的消息局部性与区域中的控制信息共享范围都需要声明。多区域的宽层可保留局部控制，展开和收拢处也可以采用不同描述与评分方案。

局部评分还有两个已定义的选择，均可放在上表任一组合中：

| 局部评分 | 结构与直觉 | 限制与待验证问题 |
|---|---|---|
| cat | 将当前内容、短长期记忆、对数统计量及逐坐标交互拼接，接单隐藏层 MLP；各列权重可以分别解释异质特征 | 结构简单，容易作为基线；特征尺度、统计量捷径和记忆匹配质量须检查 |
| match | 三组分别非线性编码与归一化，加入显式内容—记忆点积和门控残差 | 对匹配任务的结构性偏好更强；增加参数和准备，归一化也可能削弱有用的绝对幅值信息 |

拼接不要求各维具有同一物理含义，单隐藏层网络也能学习非线性交互。分组方案提供不同的归纳偏好，不能从结构直接推出质量更好；只分拆线性矩阵再相加则没有改变函数。两种方案都显式保留统计量，避免要求读者把记忆总权重解释成内容坐标。可在相同参数或准备成本下比较，并分别消融匹配项、残差和统计量。

局部教材式 (8a) 已定义每节点以自身内容匹配自身记忆的函数。将 region_score 固定为 ind／att，可分别检验局部匹配与区域共享 query 的贡献；match 不要求启用区域 Attention。

## 3. 匹配评分、预算分配与梯度

### 3.1 可行域决定什么

局部教材将评分与预算分开。共同可行域为
$0\le c_v\le\mu_v,\ \min(1,\sum_v\mu_v)\le\sum_vc_v\le k_j$；
在其上分别使用二次、二元熵或 Shannon／Tsallis 正则。硬选择在全部评分低于阈值时保留最高分有效候选。

普通 softmax 的零温 Top-1 来自单纯形质量固定为 $1$。在唯一最高分下，单纯形 sparsemax、entmax 也趋于 Top-1；它们都能作为 Tide 的局部函数。要支持一次选择多个单位门控，应使用相应可行域。把 softmax 乘 $k_j$ 会允许单坐标超过 $1$，随后逐项裁剪又一般失去目标预算，不能直接替代这里的解。

当前质量下限还有明确代价：$M_j=\sum\mu_v\le1$ 时强制 $c=\mu$，没有评分分配自由度；$k_j=1,M_j\ge1$ 时共同阈值无效。这些性质由约束决定，换正则不会消除。未来若放松质量下限，需要另定义函数并重新核对非空传播与架构计数；当前基线保留原下限。

### 3.2 正则的比较

下表的单纯形指 $c\ge0,\sum c=1$，预算域指局部教材的 $F(\mu)$。记 $\tau=\tau_{\mathrm{soft}}$；各结论均针对精确数学函数。

| 函数或族 | 前向与反向 | 支持及训练取舍 |
|---|---|---|
| 普通 softmax | 单纯形 Shannon 解；指数归一化，Jacobian 为 $(\operatorname{diag}(c)-cc^\top)/\tau$ | 正温度全正；高度集中时小分支梯度也可能很小；唯一最高分的零温极限为 Top-1 |
| sparsemax／quad | 单纯形 sparsemax 或一般预算域的二次投影；排序分段，质量边界上的反向在自由坐标内减均值 | 可精确为零或达到上界，便于跳过工作；直接评分梯度可能消失 |
| bern | 对上界占用比例加二元熵；$c_v=\mu_v\sigma((t_v-\lambda)/\tau)$，需要时求一个质量根 | $M_j>1$ 时所有有效坐标严格位于上下界内；扩大反馈覆盖的机会，同时支付全部有效 Full，极端评分仍会数值饱和 |
| ent，$\alpha=1$ | 预算域上的 Shannon 熵；截顶指数响应加标量根 | 所有有效坐标为正，但可能触及上界；只在单纯形特例直接化为普通 softmax |
| ent，$1<\alpha\le2$ | 预算域上的 Tsallis 熵；截顶幂响应加标量根，隐式反向斜率 $c^{2-\alpha}/\tau$ | 支持精确零；自由小坐标的导数随 $\alpha$ 改变，不能据此预先判断最优质量／稀疏率 |

熵族的求根是一维单调问题，可二分，或用有区间保护的 Newton 法加速。反向可直接对最优性条件隐式求导，无须保存每次迭代；具体根区间、上下界梯度、退化分支与容差见局部教材附录 S.3。softmax 的简单闭式来自其约束形状；这里的逐节点上界、可变总质量与非空下限带来了额外标量协调。

$\alpha=2$ 时，Tsallis 正则与二次正则相差 $\frac12\sum c_v$。固定总质量时等价；总质量可变时，ent 的阈值需取 quad 的阈值加 $\tau/2$ 才复现相同门控。比较正则时要分开“数值恢复检查”和“各自调参后的任务比较”。

各正则在固定可行域的零温极限中都消失，唯一线性最优解决定共同硬端点。温度趋零时的值收敛、有限温度能否精确跳过分支、训练能否找到好评分，是三个独立问题。高温也有族差异：二次族趋于下限质量上的最小范数分配，二元熵偏好上界半占用，ent 偏好其约束下的熵最大值。

### 3.3 饱和、数据多样性与反事实

二次族取 $\mu=(1,1),k_j=1$ 的两节点例子有
$c_1=\operatorname{clip}(1/2+(s_1-s_2)/(2\tau),0,1)$。
$s_1-s_2>\tau$ 时，小幅评分扰动仍保持 $(1,0)$。门控始终在 $[0,1]$；饱和是它落在边界并保持局部不变。

这样的稳定分工可能有益。不同任务、输入和记忆可以让同一节点在其他样本上进入自由区；持续早期饱和也可能使错误分工固化。需记录每节点在各类任务、历史长度与训练时间上的自由区、任务梯度和重新进入支持的机会，判断多样性是否实际提供了覆盖。正温度熵族的非零导数也可能极小，不能单靠“处处有梯度”作优劣结论。

独立评分中，发送上界只在分配的可行域及所选正则中参与；区域 Attention 还使用它形成共享 query。因而零门控但正上界的候选，可能经 query 获得其他候选的反馈。上下文增益则有自己的内容与记忆依赖，反向须保留完整链路。

保存状态扩大未来信用路径：未激活候选的接收更新仍可在以后被 Read 或 Full 使用。是否形成有效梯度取决于后续读取、饱和和反向截断。未计算的 Full 不会自动提供该步反事实价值；稠密教师、shadow 分支或有目标的辅助评分需要额外信息和计算，须单独定义。

### 3.4 弱接收与有界增益

固定 $\gamma_v>1$ 已允许弱接收放大；context 将增益变为当前内容、记忆和统计量的有界连续函数。两者都满足 $c_v\le\mu_v\le\gamma_{\max}r_+$，同时保持写入权重 $w(r)$。弱新信息可以触发已有强记忆，发送质量与 Full 内容分别由增益／选择和记忆读取决定。

有限增益可以让有限强度沿路径恢复，例如单有效候选、增益 $4$ 时 $0.01\to0.04\to0.16\to0.64\to1$；固定有限路径上，任意趋零输入的输出仍趋零。若要求任意微小正接收都产生固定非零强度，就会破坏零处连续性。实验应比较弱记忆检索质量、误唤醒、上界饱和和路径梯度；全连接实例因每节点接收至少为 $1$，无法用于判断这个增益的前向价值。

## 4. 固定拓扑上的动态稀疏与成本

局部退火证明适用于任意固定有限正时延图；全连接、连接较丰富的 HB、稀疏 HB 和多区域结构共用同一局部证明。硬化后，有效候选非空的区域每次激活 $1$ 至 $k_j$ 个节点；具体激活者由输入和历史决定，空间边继续供其他时刻使用。永久删除边会改变空间图，属于另一项结构设计。

当前候选无论是否激活，都已支付聚合、写入与 Read。某节点不发送时，下游若失去全部输入，就不再成为候选，省去其准备、选择及可能的 Full，影响还可向后传播。全连接实例每层至少一个发送者，下一层全体节点始终接收并写入。HB 实例的每个发送者连向每个相连区域，因此所有区域每位置均到达，区域内部在精确零选择下仍可只有少数节点准备。全区域使用正温度 bern 或 ent 的 $\alpha=1$ 时，已有路径上的全正发送会覆盖所有节点；比较候选节约时须保留非空约束与正则的支持性质。

因此 selector 的设计成本应与全图工作比较。更丰富的读取可能改善分工和路径选择，也可能以额外准备成本换取更多下游节约。节点宽度、图宽度、父邻域重叠、出度、外部注入及任务依赖共同决定结果；准备成本的绝对量和占比都应实测，不能由 Full 数直接推出。

[[weighted-kv-hb-lattice-example|HB-Lattice 实例]] 给出先展开再收拢的多区域图及候选覆盖公式。可在展开前、汇合处或影响范围较大的区域试验更丰富的 Read，其他区域保持较轻配置。比较相同质量下的总工作量和时间，并记录各部分增减，才能判断这种分配是否有效。

## 5. 保留、衰减与选择历史

| 动作 | 数学含义 | 需要观察的风险 |
|---|---|---|
| 保留 | 下一状态包含本次接收更新 | 写入可能永远不被读出 |
| 衰减 | 按逻辑时间解释旧条目的读取权重 | 长空档使信息过快或过慢消失 |
| 选后清理 | Next 按已知输入和选择改变持久状态 | 可能切断长期信用 |
| 选择历史 | 为之后选择保存恢复量、次数等区域坐标 | 可能抑制持续有用节点或固化历史优势 |

KV 局部教材采用 BO、默认 Next 和单点区域历史；它的时间窗口与短期衰减属于已定义的函数。恢复惩罚、次数均衡与选后清理可以作为其他局部设计，需明确状态、更新及继续关系。

对无输入时只衰减、不产生自主事件的状态，可保存值 $z$ 和写入时间 $s$，在 $\theta$ 读取 $\Phi_{\theta-s}(z)$，其中 $\Phi_0=\operatorname{id}$、$\Phi_{a+b}=\Phi_b\circ\Phi_a$。例如 $\Phi_\Delta(z)=\lambda^\Delta z$，$0<\lambda\le1$，即可按逻辑时间惰性读取。带阈值、重置和选择的完整控制器是否可扫描，需要另外证明。

区域历史按模型序列保存；设备队列和 batch 同伴不属于已声明的模型输入。Full 读取选择时形成的快照；若下一状态需要依赖本次 Full 输出，须重新定义依赖与继续语义。临时 inbox 回收、神经状态清理和选择历史更新也应分别对应各自对象。

## 6. 怎样判断机制起作用

分别检查：描述量是否利用任务相关信息，写入是否后来被读取，区域信息共享是否改善选择，以及新增准备工作是否带来全图收益。机制消融应尽量保持图、训练暴露与成本可比，说明是否重新训练；清零某模块还可能引起分布变化。

记录候选覆盖、邻域重叠、激活、消息、KV 读写、自由与饱和坐标、梯度覆盖、分工、质量和总时间。稠密教师、校准与反事实分支的额外工作也进入账本。详细矩阵见 [[learning-risks-and-diagnostics#6.1 带权 KV 特例的退火实验|退火实验备忘]]。

机制的历史动机见 [LH 历史](../history/lh-history.md) 与 [脑科学启发](../background/neuroscience-model-ideas.md)；这些来源提供待检验的直觉。

## 7. 外部证据与适用范围

| 来源 | 已给出的结果 | 可支持的判断与边界 |
|---|---|---|
| [Martins & Astudillo, 2016，From Softmax to Sparsemax](https://proceedings.mlr.press/v48/martins16.html) | 给出 sparsemax、可计算的 Jacobian，以及多标签分类与自然语言推断实验；文中报告了有竞争力的结果和稀疏注意力 | 支持稀疏连续映射可训练；未验证 Tide 的状态路由、逐节点上界或全图节约 |
| [Peters et al., 2019，Sparse Sequence-to-Sequence Models](https://aclanthology.org/P19-1146/) | 定义连接 softmax 与 sparsemax 的 $\alpha$-entmax，研究稀疏 attention 和输出分布，并在所测形态变化与机器翻译任务中报告收益 | 支持将 entmax 纳入候选；效果来自论文任务与训练条件，不能直接外推到 KV 节点选择 |
| [Correia et al., 2019，Adaptively Sparse Transformers](https://aclanthology.org/D19-1223/) | 在机器翻译 Transformer 中学习各头的 $\alpha$，观察不同稀疏程度及注意力模式，在所测任务保持有竞争力的质量 | 支持逐模块选择稀疏程度的实验动机；本文的 $\alpha$ 是固定配置，训练 $\alpha$ 需另补反向契约 |
| [Blondel et al., 2020，Learning with Fenchel-Young Losses](https://www.jmlr.org/papers/v21/19-021.html) | 给出正则化预测及配套损失的统一框架，讨论稀疏性与梯度性质 | 对已有目标的辅助评分可设计直接预测损失；目标或教师证据须另行提供，不产生免费的未计算分支价值 |
| [Amos & Kolter, 2017，OptNet](https://proceedings.mlr.press/v70/amos17a.html) | 通过最优性条件对优化层作隐式微分，并给出二次优化层实验 | 支持优化层反向的通用途径；局部教材的一维求根与导数由自身可分目标推导，性能须在具体设备测量 |

预算域上的唯一性、零消息删除、弱接收连续性及硬化条件由局部教材证明。哪种评分、正则和增益在 Tide 中训练更好、是否抵偿额外计算，属于实验假设。优先在同图同预算下比较局部选择，再检查 HB 的下游覆盖与长期状态；各配置的训练、prefill、decode 成本分别报告。
