# Selector 与局部记忆：机制动机与设计取舍

本文分析带权 KV 候选的表达能力、梯度与成本，并区分数学结论、设计直觉和外部实验依据。函数及证明以[局部教材](../../weighted-kv-sparse-activation-example.md)为准；具体对照和推进依据见[训练实验与推进](../learning-systems/weighted-kv-experiment-plan.md)，程序正确性见[实现核对](../../weighted-kv-implementation-checks.md)。

## 1. 稀疏、反馈与分工

局部教材第 4、8 节分别说明发送强度、激活集合与选择函数的导数。quad 与 ent 的 $\alpha>1$ 能在正温度产生精确零；发送强度未触及上下限时可以响应任务梯度；有用分工则要求节点的差异对任务形成互补贡献。这些性质为研究提供不同的判断依据。

固定发送强度之和时，评分反馈比较候选的边际影响。ind 的独立描述仍经预算乘子形成竞争，因而具备学习条件分配的途径。未触及上下限的候选只有一个、可行集为单点，或各候选边际影响相同，都可能使直接评分梯度为零。丰富评分器能增加可用信息，其收益仍依赖分配层和后续任务提供反馈。

私有状态与参数为分工提供表达空间。相同输入、同参数与同历史也可保持数值对称；激活次数均衡只描述使用分布。节点承担什么任务、拥有何种互补记忆，需要自己的实验依据。

## 2. 信息来源与参数共享

| 设计轴 | 有利特性与动机 | 限制与风险 |
|---|---|---|
| 区域共享聚合 | 使用共同特征空间，减少参数；来源嵌入仍能区分来源 | 压缩后已丢失的信息通常无法由节点适配恢复 |
| 节点／来源独立聚合 | 在压缩前形成不同视角，更容易表达不同任务所需的信息 | 增加所有候选的准备与参数；私有部分需要足够输入和梯度覆盖 |
| 共享 KV 基座与私有适配 | 共享部分汇集训练信号，私有部分保留分化空间 | 适配秩限制差异；两因子同时零初始化时初始乘积梯度为零 |
| 时间摘要 sum | 按时间和权重汇集，成本较低，历史条目可广泛参与描述 | 少量相关证据可能被稀释，当前内容在汇集以后才参与判断 |
| 内容检索 qry | 当前输入先查询私有记忆，能够表达任务相关的证据检索 | 候选均支付检索成本；注意力集中可使部分条目长期缺少反馈 |
| 拼接评分 cat | 单隐藏层网络包含内容、统计量及交互项，提供较小基线 | 可能利用接收频率或记忆长度等统计捷径，特征尺度与内容使用需辨明 |
| 分组匹配 match | 分组非线性编码与归一化，显式内容—记忆匹配及残差 | 匹配相似度到执行价值仍需学习；归一化可能弱化幅值信息，乘性交互使梯度依赖两侧特征及其尺度 |
| 独立区域评分 ind | 描述较小，预算仍提供竞争，依赖关系较容易分析 | 各候选先压成标量，跨候选当前内容的关系表达有限 |
| 区域 Attention att | 共享 query 比较私有记忆；正上界的零发送强度候选可经 query 影响其他评分 | 单 query 汇集有压缩限制；反馈更耦合，仍缺少未执行 Full 的直接反事实价值 |

memory、local_score、region_score 是独立设计轴。cat 已经含非线性与内容—记忆逐坐标交互；match 通过分组编码、归一化与显式点积给出进一步的结构偏好。局部匹配不要求启用区域 Attention，内容检索也可接独立评分。

参数共享与数值复用具有各自条件。来源类别、载荷与出现次数相同，且函数相同，才可共同求值；HB 的不同邻域即使共享参数，通常仍产生不同聚合。全连接实例同层面对相同来源载荷，更依赖私有参数和历史内容形成差异。HB 的邻域已提供不同视角，同时带来上游路径暴露不均的风险。

区域 query 按发送上限加权，具有弱候选消失性质。扩大区域会增加控制信息范围；多个局部区域则分别形成 query。区域匹配的单 query 对候选数是线性工作量，是否值得采用应连同其影响的下游工作判断。

## 3. 选择函数、温度与梯度取舍

### 3.1 持续稠密与精确稀疏

评分模块、评分到发送强度的函数、温度日程可以分别选择。区域 Attention 提供 query 与 keys 的匹配，随后既可采用固定尺度的稠密分配，也可采用产生精确零的函数。稠密分配可以作为训练与推理始终使用的最终模型；固定图、私有记忆和多来源传播仍提供架构研究空间。

固定总强度 Attention、直接 Attention、约束 Shannon 与可稀疏的约束选择，其发送约束、激活范围和求值方式集中在[局部教材 §7.11](../../weighted-kv-sparse-activation-example.md#711-发送规则的比较)。固定总强度 Attention 有普通和接收加权两个版本，均以固定正温度的稠密训练、推理为完整设计。约束 Shannon 与可稀疏选择都属于式 (12) 的软选择。普通 softmax 本身也等价于熵正则优化；比较时使用具体发送规则的名称。

各族的响应与导数见局部教材第 8 节。下表按上述顺序比较研究取舍，分别列出可稀疏组的 quad 与 ent，并补充 bern。

| 候选 | 有利特性 | 风险与成本 |
|---|---|---|
| 固定总强度 Attention：uniform | 普通 softmax，无需求根；每次非空选择分配单位总强度；弱接收节点可凭记忆匹配获得大份额，低接收总量仍有评分反馈 | 全部候选计算；弱线索和弱噪声均可能触发单位总强度，无法通过整体减小发送表示信息不足 |
| 固定总强度 Attention：reception | 同样保持单位总强度，以接收相关权重偏向较强输入，省去外乘 $\mu$ 的抑制 | 接收偏好可能压低弱线索的重要记忆；额外的归一化权重依赖需要观察其梯度 |
| 直接 Attention | 省去求根；至少两个有效候选时没有约束截断造成的精确零或上限区，低总量下仍可依评分调整 | 全部有效 Full 参与；上限影响归一化及发送，总强度可衰减，微弱候选的反馈仍可能很小 |
| 约束 Shannon | 持续混合多个节点，同时保留区域发送强度保障 | 全部有效 Full 与广播均有成本；可达到上限或被约束固定分配，小发送强度仍可能只有很弱的反馈 |
| 可稀疏的约束选择：quad | 精确零可减少工作；尚未触及上下限的小分量仍有 $1/\tau$ 的响应斜率；便于建立基线 | 严格零／上界饱和后直接评分反馈消失；低温时上下限之间的响应较陡 |
| 可稀疏的约束选择：ent，$1<\alpha<2$ | 精确零可减少工作，接近零时响应更平缓 | 小发送强度的响应斜率 $c^{2-\alpha}/\tau$ 较小，微弱候选的恢复反馈可能更弱 |
| 其他约束稠密候选：bern | $M>1$ 时有效候选的发送强度保持在上下限之间，扩大直接反馈覆盖机会 | 正温度执行所有有效 Full；极端占用比例下梯度仍可很小 |

ent 的 $\alpha=2$ 与 quad 具有局部教材式 (29) 的阈值移位关系。约束求解与反向见附录 S.3，直接 Attention 见附录 S.5，固定总强度 Attention 见附录 S.6。配对比较的共同条件与解释范围见[实验计划 §5.1](../learning-systems/weighted-kv-experiment-plan.md#51-发送规则的配对比较)。

持续稠密让每个有效候选的 Full 都有当前步反馈通路，有利于研究多节点合作。精确稀疏可以减少干扰与计算，并形成较明确的输入相关分工；早期排除也可能使部分节点缺少训练。两者均需打破参数与历史的对称，也均可能过度集中于少数节点。正发送强度、非零导数和有效任务更新分别计量。

### 3.2 query 的反馈与优化

局部教材 §8.5—8.6 给出普通 softmax、直接 Attention 的 Jacobian 及 query 梯度；§8.3 给出约束下的竞争反馈。共享 query 都会使候选相互影响。稀疏选择可以将某些候选的直接评分反馈截断；Attention 的小权重则可能使这条反馈很弱。正上界的未激活候选还可能经共享 query 或未来记忆参与训练，当前 Full 的反馈覆盖应单独记录。

固定评分、发送上限与正温度时，式 (12) 的选择子问题严格凹，有唯一解；直接 Attention 由显式公式唯一确定。对产生 query、keys 和内容的网络参数进行训练时，整体目标通常非凸。固定 keys、局部评分与发送上限后，quad 从 query 到发送强度是分段仿射，普通 softmax 与直接 Attention 对 query 光滑；一般约束 Shannon 仍有达到上限时的分支边界。这些事实无法给出整体目标非凸程度或训练难度的排序。

可具体分析的差别是平坦区域、分支切换与梯度尺度。同一样本上的饱和可稳定分配，零发送还能省去工作；其他输入和历史可能使节点重新进入未触及上下限的区间，也可能使早期分配长期保持。数据多样性提供恢复机会，其实际覆盖由实验确认。

对能精确稀疏的族，低温可能扩大零值或上限固定的区域，并使剩余过渡区较陡。固定且分离的评分可完全饱和，跨样本接近边界的评分则可能产生尖峰。普通 softmax 降温也会强化竞争；固定温度避免日程主动放大 $1/\tau$，但 query/key 范数及匹配尺度增长仍能使权重更集中，梯度到 query 的大小还受 keys 影响。归一化、长期 Jacobian 乘积、求解误差和成本代理的近零斜率也会影响稳定性。

### 3.3 接收强度与发送强度

局部教材 §7.11 的算例比较了两项独立选择：每节点发送强度是否受接收相关的 $\mu_v$ 限制，以及整个区域发送多少。直接 Attention 将 $\mu$ 同时用于归一化和外乘；约束 Shannon 保留 $c_v\le\mu_v$，再协调区域总和；固定总强度 Attention 将每节点上限取为 $1$，按普通或接收加权的比例分配一个单位。

固定总强度 Attention 允许弱线索唤醒的旧记忆获得大份额。普通版本把分配交给评分；接收加权版本另加入较强接收应获得更多关注的偏好。接收强度也可能表示已被分摊的路径份额，其大小与信息价值之间没有普遍等价关系；两种版本的任务表现需要实验区分。

它的代价是有候选参与时，总发送强度保持为 $1$。弱输入有效时，这支持后续计算；弱输入无效时，也可能放大噪声或过时记忆。任务仍能通过内容函数产生很小或相互抵消的内容，但发送强度本身不表达区域整体的低可信度。两版本都按 $w(r)$ 写入，因此强记忆输出与谨慎写入新证据可以同时发生。

有多个参与候选时，固定总强度 Attention 的评分响应采用普通 softmax 的 Jacobian，低接收总量也保留评分分配通路。约束 Shannon 在 $M\le1$ 时由约束固定分配；直接 Attention 的评分反馈则带各自的 $\mu_v$。这些是局部导数的差别；评分集中、共享 query、历史状态和任务的实际反馈仍共同决定训练。

固定温度与无求根均不保证接收权重梯度小。reception 的正权重分支有 $\partial c_v/\partial\mu_u=c_u(\mathbf1[v=u]-c_v)/\mu_u$；相对权重敏感性可能随小 $\mu_u$ 增大。uniform 在固定评分时没有这条直接通路，使用 att 时仍保留 $\mu$ 加权 query 的依赖。直接 Attention 的上限导数由局部教材 §8.6 给出；各完整链路分别测量。

全连接单位输入实例每节点 $\mu=1$，各稠密配置在 Shannon 取 $k=1$ 时具有相同前向。HB 的非单位接收提供区分场景：[HB 实例 §2.5](../../weighted-kv-hb-lattice-example.md#25-稠密发送的强度传播) 对同一图给出 direct 的逐层衰减，以及固定总强度 Attention 的单位区域发送。接收与发送强度、写入权重和实际 Full 工作分别记录。

## 4. 总和下限与弱接收增益

### 4.1 已定义的下限

局部教材的式 (12) 固定 $b_\Sigma(\mu)=\min(1,\sum_v\mu_v)$。它既保证有效候选非空时有发送，也给出区域发送强度保障；在局部教材 §4.2 的单点可行集情形，评分对本次分配的导数为零；这一性质由约束决定。直接 Attention 的总强度由其公式确定；固定总强度 Attention 在有正基权重时取 $S=1$。

$b_\Sigma\le S\le\min(k,M)$ 逐区域、逐次选择成立。广播的每条出边各得到完整载荷，边上的总强度还乘入出度；下游各区域的接收取决于连接覆盖，内容尺度取决于 Full。局部强度范围提供一项控制条件，图上的传播与总工作仍需单独判断。

全部区域使用式 (12) 时，两个现有单位输入组合都维持每区 $M\ge1$；全连接更逐节点保持 $\mu=1$。HB 允许单节点弱接收，局部分配余量与未触及上下限的候选应结合整个区域理解。含直接 Attention 的 HB 组合按实际总强度重新判断。

### 4.2 待绑定的下限候选

一个研究候选是在同一可行域定义中将下限改为

$$
b_{\max}(\mu)=\max_v\mu_v,\qquad \max\varnothing=0.
$$

它连续，关于无穷范数为 $1$-Lipschitz；非零上界族上满足 $0<b_{\max}\le b_\Sigma$，当每个 $\mu_v\in\{0,1\}$ 且至少一个为 $1$ 时，两者都为 $1$。这些事实为沿用可行恢复列和硬运行归纳提供条件。纳入局部函数族时，应补齐该候选的连续性、硬化与反向定义，再建立独立配置；现有约束选择仍绑定 $b_\Sigma$。

| 下限 | 潜在收益 | 代价与边界 |
|---|---|---|
| $b_\Sigma$ | 更强的区域发送强度保障，低总量时保留全部弱候选 | $M\le1$ 时分配被固定 |
| $b_{\max}$ | 多个弱候选之间可减小部分候选的发送强度 | 需重新检验区域发送强度之和至少为 $1$ 的传播性质；放松可行域仍可能得到饱和解或只有一个未触及上下限的候选 |

唯一最大上界处，$b_{\max}$ 的直接导数集中在该坐标；平票处需声明广义或单侧导数。上界还可通过约束、正则及区域 query 影响选择，这些通路继续存在。最大值的不可微点本身不表示数值发散。

固定 $\mu=(0.9,0.8),t=(-2,-1),k=1$ 时，原下限的软零温极限为 $(0.2,0.8)$，最大上界下限的极限为 $(0.1,0.8)$，原硬函数为 $(0,0.8)$。这个例子中，改变下限后，软选择的零温极限仍与硬选择不同。单位输入的整网问题依赖随温度变化的上界及发送上限为零或一的硬运行。

另一个提议 $b=\min(1,M/2)$ 连单位单候选的端点也会改变：$\mu=1,t=-1,k=1$ 时 quad 的软解对任意正温度均为 $1/2$，原硬函数为 $1$。采用它需重新选择硬目标及传播性质。

### 4.3 有界发送增益

固定 $\gamma>1$ 已允许弱接收放大；context 进一步依据当前内容、记忆和统计量调整增益。局部教材 §9.4 证明固定有限路径上的零边界连续性，并给出弱信号恢复到单位强度的例子。写入仍按实际接收权重，记忆唤醒与新证据强度分别表达。

增益有机会提供评分分配以外的学习通路，也可能放大无效信息、增加后续工作，并更早触及上界截断。全连接单位输入下增益没有前向差异；HB 的弱接收为这一候选提供可辨别的场景。

## 5. 固定拓扑与全图成本

局部教材的单位输入硬化定理比较式 (12) 与式 (14)，适用于固定有限正时延图及有限切面，评分条件核对硬运行。直接 Attention 使用自身的固定正温度连续性。空间边在不同输入和历史中继续可用；永久删边改变另一个架构对象。

接收候选已经支付 Agg、写入与 Read，零发送强度首先省去 Full 和发送。下游节点若失去全部输入，还省去整次准备与状态更新。全连接实例始终覆盖下一层全部节点；HB 按激活者邻域并集确定候选，父邻域重叠会减少独占覆盖。

更强的 selector 可能以更多当前准备换来更少或更有用的后续计算，收益取决于出度、重叠、输入注入和任务需求。节点宽度、激活数与准备成本占比都只是部分信息。全部区域采用固定总强度 Attention、直接 Attention、bern 或 Shannon 时，当前 HB 的正温度运行覆盖全图节点；精确稀疏族才可通过零发送强度减少该覆盖。

局部教材附录 S.4 和实例给出工作量表达式；实际训练、prefill、decode 的质量与成本在实验文档中比较。

## 6. 私有状态与未来信用

BO 与默认 Next 保留当前候选的接收更新，增加未来可读的信息。未来读取、截断反向及上游输入覆盖决定这些写入获得何种反馈。未执行的 Full 没有该步直接反事实读出；教师、shadow 分支或辅助目标需要额外信息与计算。

保留、衰减、选后清理与选择历史分别定义状态行为。恢复惩罚或使用次数历史可改变以后选择，也可能抑制有用节点；推理中采用这些量时，须把它们纳入状态、更新与继续关系。

对无输入时只衰减、不产生自主事件的状态，可保存值 $z$ 与写入时刻 $s$，在 $\theta$ 读取 $\Phi_{\theta-s}(z)$，其中 $\Phi_0=\operatorname{id}$、$\Phi_{a+b}=\Phi_b\circ\Phi_a$。例如 $\Phi_\Delta(z)=\lambda^\Delta z$、$0<\lambda\le1$。阈值、重置与选择加入后的连续性和联合求值需按完整函数判断。

区域历史按模型序列保存。Full 读取既定快照；若下一状态要依赖本次 Full 输出，需重新给出依赖与继续语义。缓存回收、神经状态清理和区域历史更新分别对应自己的对象。

## 7. 外部证据与适用范围

| 来源 | 研究结果 | 对本设计的启发与边界 |
|---|---|---|
| [Martins & Astudillo, 2016，Sparsemax](https://proceedings.mlr.press/v48/martins16.html) | 给出稀疏映射、Jacobian，以及多标签分类与自然语言推断实验 | 支持精确稀疏连续映射可训练；未验证私有状态与长路径路由 |
| [Peters et al., 2019，Sparse Sequence-to-Sequence Models](https://aclanthology.org/P19-1146/) | 定义连接 softmax 与 sparsemax 的 entmax，在形态变化与机器翻译任务中报告收益 | 支持比较正则形状；每个候选的发送上限与总和区间由本文自己的定义处理 |
| [Correia et al., 2019，Adaptively Sparse Transformers](https://aclanthology.org/D19-1223/) | 学习不同头的稀疏程度并观察不同注意力模式 | 支持逐模块稀疏差异的研究；当前局部族使用固定 $\alpha$ |
| [Blondel et al., 2020，Fenchel–Young Losses](https://www.jmlr.org/papers/v21/19-021.html) | 正则化预测与配套损失的统一分析 | 可指导有目标的辅助评分；监督或教师目标需另外提供 |
| [Amos & Kolter, 2017，OptNet](https://proceedings.mlr.press/v70/amos17a.html) | 通过最优性条件对优化层隐式微分 | 支持优化层的反向方法；本文标量求根和导数由自身目标推导 |
| [Jang et al., 2017，Gumbel-Softmax](https://arxiv.org/abs/1611.01144) | 低温更接近离散采样，同时提高梯度方差；采用降至非零温度的方案 | 提供连续松弛与温度取舍证据；随机单纯形采样与本文确定性预算不同 |
| [Maddison et al., 2017，Concrete](https://arxiv.org/abs/1611.00712) | 连续松弛可优化离散随机图；作者在所做实验中未发现退火或自动调温很重要 | 支持保留固定正温对照，避免把退火设为普遍必需 |
| [Hazimeh et al., 2021，DSelect-k](https://arxiv.org/abs/2106.03760) | 平滑稀疏门控在所测多任务问题中具有竞争力；强调避免初始饱和造成零梯度 | 支持检验早期反馈与硬化的取舍；二进制编码和正则机制不同 |
| [Fedus et al., Switch Transformers](https://arxiv.org/abs/2101.03961) | Top-1 专家选择可有效训练，采用选择性高精度、初始化与辅助机制 | 提供硬成员选择的正面证据；其选中 softmax 权重与辅助信号不同于本文硬 $c=\mu$ |
| [Zoph et al., 2022，ST-MoE](https://arxiv.org/abs/2202.08906) | router z-loss 改善稳定性；更紧更新裁剪及部分噪声方案存在质量代价 | 稳定性干预需同时评价质量，具体损失与模型条件不能直接移植结论 |

这些证据支持开展候选比较。Tide 的长期私有状态、广播邻域和跨层覆盖仍需自身结果；数学保证、外部任务结果与研究假设分别维护。机制历史见 [LH 历史](../history/lh-history.md)与[脑科学启发](../background/neuroscience-model-ideas.md)。
