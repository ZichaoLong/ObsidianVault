# 带权 KV：训练实验与推进

本文组织带权 KV 的训练目标、候选比较和推进依据。[局部教材](../../weighted-kv-sparse-activation-example.md)定义计算函数；[全连接实例](../../weighted-kv-layered-example.md)与 [HB-Lattice 实例](../../weighted-kv-hb-lattice-example.md)定义图与边界；[实现核对](../../weighted-kv-implementation-checks.md)规定正确性证据。设计动机和外部研究见 [Selector 与局部记忆](../architecture/selector-and-memory.md)，一般学习风险见 [学习风险与诊断](learning-risks-and-diagnostics.md)。

以下方案是研究对照。具体规模、数据、优化器、测量及结果由下游实验记录给出。

## 1. 研究问题与比较单位

每次比较固定一个图、局部函数组合、任务读出和训练算法。配置名称沿用局部教材附录 S.2；另外声明数据、随机种子、优化器、温度日程、损失系数、状态管理和部署配置。

| 问题 | 可比较的选择 | 主要依据 |
|---|---|---|
| 持续稠密与精确稀疏各适合哪些任务 | §5.1 的直接 Attention、约束 Shannon、可稀疏的约束选择；bern 另作覆盖比较 | 任务质量、多节点合作、发送强度、反馈与全部准备、Full、传播成本 |
| 更多选择信息能否改善分工 | sum／qry、cat／match、ind／att | 记忆使用、条件性选择、任务梯度及新增准备成本 |
| 邻域差异能否形成有用专长 | 全连接与 HB、不同聚合共享方式 | 输入覆盖、节点互补性、训练暴露与整图成本 |
| 弱接收能否唤醒有用记忆 | 固定单位增益、可训练固定增益、context | 接收与发送强度、误唤醒、上界饱和、后续质量 |
| 降温或硬部署是否值得采用 | 固定正温、有限降温、独立硬选择评估 | 质量、梯度、实际激活数量和严格激活数需求 |

先比较固定图上的局部函数，再比较固定局部函数下的图。参数量、数据暴露与总计算通常无法同时完全匹配，应提供互补对照并列明剩余差异。

## 2. 任务与训练目标

### 2.1 语言模型接入

两个架构实例均给出因果表示 $y_t\in\mathbb R^d$。独立语言模型可用 token 嵌入作为入口内容 $h_t$，声明词表大小 $n_{\mathrm{vocab}}$ 和矩阵 $W_{\mathrm{vocab}}\in\mathbb R^{n_{\mathrm{vocab}}\times d}$。沿用局部教材的归一化函数，定义

$$
\begin{aligned}
p_t&=\operatorname{softmax}(W_{\mathrm{vocab}}\mathcal N_d(y_t)),\\
\mathcal L_{\mathrm{task}}
&=-\frac1{N_{\mathrm{tok}}}\sum_{t\in\mathcal T_{\mathrm{sup}}}
  \log p_t(x_{t+1}^{\mathrm{tok}}),\qquad
N_{\mathrm{tok}}=|\mathcal T_{\mathrm{sup}}|\ge1.
\end{aligned}
\tag{1}
$$

$\mathcal T_{\mathrm{sup}}$ 是监督位置集，$x_{t+1}^{\mathrm{tok}}$ 是下一 token 标签。其他任务独立声明读出、监督位置与损失。

### 2.2 稠密暴露与教师

约束 Shannon 与直接 Attention 分别由局部教材 §7.8、§7.9 定义，均可以独立训练、推理，也可以作为教师。为预训练 Full、记忆或单独考察按上限分配的暴露，还可采用以下不依赖评分的控制。记 $M_j=\sum_{v\in C}\mu_v$，定义

$$
c_v^{\mathrm{dense}}=
\begin{cases}
\displaystyle\mu_v\frac{\min(k_j,M_j)}{M_j},&M_j>0,\\
0,&M_j=0.
\end{cases}
\qquad
A^{\mathrm{dense}}=\{v:c_v^{\mathrm{dense}}>0\},\quad K_j=|\mathcal R_j|.
\tag{2}
$$

其发送强度之和为 $\min(k_j,M_j)$，满足原软可行域，对全部正上界候选给正发送强度。SelStep 返回 $(A^{\mathrm{dense}},(c_v^{\mathrm{dense}})_{v\in C},*)$，空候选返回空支持、空控制族和原历史。它沿用 Upd、Read、Next 和 Full，替换分配函数；分配不依赖评分，因此单独使用时，分配对评分的导数为零。给零发送强度补一次廉价零 Full 仍只有零数值贡献，稠密暴露使用式 (2) 的正发送强度。

稠密教师在同一外部序列上运行自己的轨迹与缓存，产生 $p_t^{\mathrm{teach}}$；学生运行自己的轨迹。可先训练并固定教师，蒸馏时停止教师目标的梯度。教师、间歇稠密校准或 shadow Full 的额外工作均计入训练预算，注明参数共享、状态写入和梯度归属。

### 2.3 成本代理与联合损失

记 $\mathcal E_C$ 为学生序列中全部候选的 $(v,\theta)$ 坐标。给节点固定参考成本 $C_v^{\mathrm{ref}}>0$，取 $\epsilon_{\mathrm{cost}}>0$ 和非负系数 $\lambda_{\mathrm{cost}},\lambda_{\mathrm{dist}}$，定义

$$
\begin{aligned}
\phi(c)&=\frac{c}{c+\epsilon_{\mathrm{cost}}},\\
\mathcal L_{\mathrm{cost}}
&=\frac1{N_{\mathrm{tok}}}\sum_{(v,\theta)\in\mathcal E_C}
 C_v^{\mathrm{ref}}\phi(c_{v,\theta}),\\
\mathcal L&=\mathcal L_{\mathrm{task}}+
 \lambda_{\mathrm{cost}}\mathcal L_{\mathrm{cost}}
 +\frac{\lambda_{\mathrm{dist}}}{N_{\mathrm{tok}}}
  \sum_{t\in\mathcal T_{\mathrm{sup}}}
  \operatorname{KL}\bigl(\operatorname{stopgrad}(p_t^{\mathrm{teach}})\,\|\,p_t\bigr).
\end{aligned}
\tag{3}
$$

stopgrad 的前向为恒等，反向对其输入贡献为零。无教师时取 $\lambda_{\mathrm{dist}}=0$ 并省去教师计算。该成本代理对较大门控近似计一次，对趋零发送强度连续归零。它的导数为

$$
\phi'(c)=\frac{\epsilon_{\mathrm{cost}}}{(c+\epsilon_{\mathrm{cost}})^2},\qquad
\phi''(c)=-\frac{2\epsilon_{\mathrm{cost}}}{(c+\epsilon_{\mathrm{cost}})^3}.
\tag{4}
$$

固定发送强度之和与相同参考成本时，凹代理偏好集中分配；较小的正发送强度有较大的成本导数，经共同预算反向后可进一步减小。完全相等的发送强度给出相同成本导数，中心化后评分梯度为零；任务反馈与初始差异仍影响分化。精确零发送强度还可能处于零评分梯度分支。

$\phi'(0)=1/\epsilon_{\mathrm{cost}}$。过小的 $\epsilon_{\mathrm{cost}}$ 会增大近零处斜率，与低温响应叠加；应同时观察温度、成本系数、未触及上下限的候选及实际梯度。该目标表达候选上的激活成本，下游候选存在、邻域重叠和端到端时间按全图测量。引入可微下游成本预测时，另行定义目标、反向与校准依据。

发送规则的首组比较按 §5.1 只使用任务目标；成本项和教师各自另作对照。持续稠密时，减小若干正发送强度可能降低上述成本代理，但实际 Full 与消息仍存在，需按真实运行计量。

## 3. 训练与部署选择

### 3.1 初始化与反馈覆盖

初始配置应让多个候选获得有效任务反馈。quad 在 $\mu_v=1$、$|C|>k_j$ 时，调整后评分接近 $\tau k_j/|C|$ 并带小差异，可让多个候选满足 $0<c_v<1$，同时使发送强度之和接近 $k_j$；其他族可按局部教材式 (28) 的响应反推评分尺度。高温下的发送强度之和依正则而异，局部教材 §8.4 给出极限性质。

节点可使用同尺度、带小差异的初始化与非零小残差。分层网络可将 $\alpha_{\mathrm{att}},\alpha_{\mathrm{ff}}$ 约为 $(2L)^{-1/2}$ 作为待校准起点；$\alpha_{\mathrm{out}}$ 取小正值。输出残差精确为零时，主任务暂时无法经内部输出训练该路径。KV 适配器的两个因子同时为零，也会使乘积路径的两侧初始梯度均为零。

稠密起点、直接软训练与间歇校准应分别比较。未激活候选仍保留接收写入；这些写入能否得到未来反馈，取决于读取与反向截断。HB 中未收到输入的节点连本地准备都没有发生，训练覆盖还依赖上游路径。

### 3.2 温度与部署配置

发送规则先按 §5.1 选择，温度日程与硬部署再分别比较：

| 方案 | 选择依据 | 需要观察 |
|---|---|---|
| 固定正温训练与推理 | 直接 Attention、约束 Shannon、可稀疏的约束选择均可持续使用 | 发送强度、激活数量、任务反馈、质量与全部计算成本 |
| 有限降温后保留约束软选择 | 固定正温已有可用结果，再检验更集中分配是否值得 | 评分间隔相对温度、梯度尖峰、覆盖变化、质量—成本曲线 |
| 硬选择推理 | 需要每区每次严格最多 $n$ 次 Full 时取 $K_j=k_j=n$ | 独立软硬轨迹误差、状态差异、间隔分布及部署质量 |

上述正温度函数都取 $K_j=|\mathcal R_j|$，实际激活数量按正分量计数。soft 使用 $k_j$ 约束发送强度之和；direct 不使用 $k_j$、阈值或预算正则。需要硬推理最多激活 $n$ 个时，软训练的 $k_j=n$ 仍只约束强度之和。采用硬函数时直接调用局部教材式 (14)，不把零温度代入正温响应。

先保留固定正温对照，再决定是否有限降温；硬部署单独评估。局部教材的硬化定理比较式 (12) 与式 (14)，固定参数、输入和有限切面；direct 及含 direct 的组合不在该定理范围内。训练日程同时改变参数时应按实际轨迹观察。发送强度依赖评分相对温度的尺度，约束选择使用调整后评分 $s-\eta$；“适中温度”也需相对这一尺度理解。quad 或 ent 的 $\alpha>1$ 停止降温时，也可能已有许多发送强度为零或达到上限的候选。

软硬比较使用相同参数与外部输入，从各自初态独立重放完整缓存轨迹。部署时的 soft/direct/hard 选择与训练日程分别记录。继续硬训练需另选替代梯度、探索或辅助目标；当前硬门控的分数排序在严格间隔内局部不变。

### 3.3 训练中的状态

每条序列保存自己的逻辑历史；声明打包、重置、反向截断、参数更新后的缓存重算或保留策略。改变正则、评分、增益或位置配置时，记录重训、微调及状态转换。已有权重形状相容只解决装载问题，缓存与前向的一致性按实现核对文档另验。

## 4. 推进顺序与决定条件

在所选配置已有实现正确性证据后，按下表形成逐步可解释的比较。每一步保留前一步对照；出现语义或数值偏离时，先回到对应实现核对项。

| 步骤 | 研究问题与设置 | 观测与下一步依据 |
|---|---|---|
| 建立基线 | 全连接与 HB 分别采用 sum、cat、ind、固定 $\gamma=1$、quad、固定正温；固定位置与窗口 | 确认任务可学习、未触及上下限的区间与梯度有覆盖，记录全图成本后再扩大比较 |
| 比较发送规则 | 固定评分模块，采用 §5.1 的三组对照；bern 另作覆盖比较 | 分别判断发送规则与约束内分配的影响；持续稠密可保留为最终配置 |
| 增加选择信息 | 分别引入 qry、match、att，再比较少量组合及聚合适配 | 检查新增信息的使用与分工，依据增量质量和全图成本决定保留范围 |
| 比较 Attention 分配 | 用同一 att 评分重复 §5.1 的三组对照 | 检查共享 query 是否改变收益，再决定是否引入退火或成本压力 |
| 检验弱接收 | 在确实出现弱接收的 HB 配置中比较增益；总和下限研究候选另建配置 | 观察 $r,w,\gamma,\mu,c$、误唤醒、发送强度保障和路径反馈 |
| 比较温度与部署 | 固定正温对照有限降温；另做硬选择重放 | 以质量、支持、梯度和部署激活数要求决定采用方案 |
| 扩展形状 | 固定局部组合后改变邻域、区域划分、窗口和位置配置 | 检查覆盖、记忆范围及成本变化；按任务收益选择更大规模 |

全部区域使用约束软选择时，两种实例均有每区 $M_j\ge1$。全连接对约束软选择、直接 Attention、硬选择及其逐区域组合还逐节点满足 $\mu_v=1$，因而 fixed/context 增益没有前向差异，约束软选择的原下限与研究候选 $b=\max_v\mu_v$ 也相同。HB 使用 direct 或混合选择时逐层测量 $r,w,\mu,c$ 及其总和；直接发送可能逐层衰减。约束选择另记录 $M_j-b_j$ 及未触及上下限的候选数。

约束软选择的 $k_j=1$ 时共同阈值无效；direct 对共同评分平移不变。att 中 $\alpha_j^{\mathrm{loc}}=0$ 时 cat/match 不进入最终评分；$\alpha_j^{\mathrm{sel}}=0,\alpha_j^{\mathrm{loc}}=1$ 恢复 ind 的数值。选择对照前先核对这些生效条件。

## 5. 单项比较与扩展

### 5.1 发送规则的三组对照

主比较采用直接 Attention、约束 Shannon、可稀疏的约束选择；最后一组分别取 quad 与 ent 的固定 $\alpha=1.5$。数学性质集中在[局部教材 §7.10](../../weighted-kv-sparse-activation-example.md#710-发送规则的比较)，配置映射见其附录 S.2。约束 Shannon 与可稀疏选择都使用 selection_mode=soft；硬选择作为 §3.2 的另项部署比较。

各组固定相同图、记忆、聚合、评分模块、增益、窗口和位置配置。约束组先取 $k_j=1$，温度均固定为正值，例如取 $1$，并取 $\lambda_{\mathrm{cost}}=\lambda_{\mathrm{dist}}=0$。使用 att 时，先取 alpha_loc=0、alpha_sel=1，保持 query、key 的产生方式相同；用 ind 重复比较可检查共享 query 的作用。

| 比较 | 保持共同的部分 | 要回答的问题 |
|---|---|---|
| 直接 Attention 与约束 Shannon | 持续激活全部有效候选、相同评分模块与其余局部函数 | 归一化、区域发送总和约束及相应反向，如何影响强度传播、记忆利用、训练与求值成本 |
| 约束 Shannon 与可稀疏的约束选择 | 同一约束定义、$k_j$、评分阈值、评分模块与其余局部函数 | 改变正则后的分配、梯度和激活范围，能否改善分工与质量—计算取舍 |

局部分配比较固定同一份 $(s,\mu)$；完整训练与评估则各自运行消息和缓存轨迹，实际评分与发送上限可能不同。直接 Attention 与可稀疏选择的比较考察整体质量与计算成本，同时包含发送约束与分配函数的变化。上表两项对照帮助解释这些变化；精确零带来的工作减少仍按实际 Full、广播与下游候选计量。

[全连接实例 §2.5](../../weighted-kv-layered-example.md#25-固定尺度的稠密-attention-组合) 中，direct 与 $k_j=1$ 的约束 Shannon 具有相同前向及评分导数，适合核对等值与求值成本。HB 的非单位上限会区分两者：记录逐层强度、达到上限的比例、上限梯度及求解成本，复现 [HB §2.5](../../weighted-kv-hb-lattice-example.md#25-直接-attention-的强度传播) 的衰减算例。在当前 HB 中，全部区域采用任一稠密规则都会覆盖全部节点，空间图仍保留原有稀疏邻接。

先给相同温度下的比较，并报告评分差相对温度的分布，再给各族独立调参结果。固定温度仍允许 query/key 范数和匹配尺度随训练变化。bern 可另作约束下的稠密候选，考察占用比例与反馈覆盖。相同数据暴露与相近总计算分别报告，所有候选的准备及实际 Full 均计入预算。

### 5.2 其他设计轴

| 设计轴 | 需保持可比的内容 | 主要诊断 |
|---|---|---|
| sum／qry，ind／att | 先固定局部评分、发送规则与图，分别比较记忆检索和区域共享信息 | Read 成本、query/key 梯度、记忆使用及选择质量 |
| cat／match | 信息范围、预算；另给相近参数量或准备成本对照 | 统计量依赖、内容—记忆打乱、匹配与残差消融 |
| ent 的形状参数 | 固定 $\alpha$ 独立训练，再考虑逐区域组合 | $\alpha=2$ 的等值检查取 $\eta^{\mathrm{ent},2}=\eta^{\mathrm{quad}}+\tau/2$；训练 $\alpha$ 另补反向定义 |
| 聚合共享与适配秩 | 来源绑定、宽度及输入覆盖 | 压缩前的信息差异、共享计算、私有参数梯度与节点互补性 |
| 增益与总和下限 | 保留原下限和单位增益对照；新下限使用独立函数配置 | 强度沿路径变化、最大上界与饱和、传播保障、非空性 |
| 较少／较多 HB 邻接 | 局部函数、区域和任务 | 可达范围、父邻域重叠、候选并集、消息数与有效更新 |
| 单层一个／多个区域 | 可比总预算并报告区域数 | 控制信息范围、每区强制非空的成本及局部专长 |
| 总和区间／固定总和 | 将用满预算定义为 $\sum c_v=\min(k_j,M_j)$ | 用量与集中度；$k_j=1$ 时两种总和约束重合 |
| 窗口、位置与描述宽度 | 每次只改变一个因素，再比较异构组合 | 长程任务、写到读延迟、缓存、检索与读取带宽 |

位置实验先使用全历史完整 RoPE 的基线，再在同一窗口比较 NoPE、完整和部分 RoPE；随后改变窗口，比较窗口 RoPE 与全历史 NoPE 的区域组合。Read 与 Full 的位置配置分别记录，可选距离衰减作为独立消融。长度外推做独立长度扫描，报告训练与验证长度、频率、坐标尺度和任务质量。位置与分块正确性使用实现核对文档的固定参数比较。

循环记忆或永久删边属于进一步扩展。循环记忆先给出状态、更新、读取、Full、缺席与继续规则，以及自己的连续性和批量求值论证；删边需重新绑定图、来源与边界。完成定义后再纳入本表的对照。

## 6. 观测与解释

| 观测 | 记录内容 | 解释边界 |
|---|---|---|
| 任务质量 | 整体及任务类别、长度分组的损失或正确率 | 同时给相同数据暴露与相近计算预算的结果 |
| 激活与发送强度 | 逐层 $r,w,\mu,c,\sum c$，$\lvert C\rvert,\lvert A\rvert$，零／介于上下限之间／达到上限的比例；约束组另记 $b,k$ 和间隔 | 激活数量、发送强度之和与正典容量 $K_j$ 分别解释，检查路径衰减 |
| 有效梯度 | 分模块范数、更新量、query/key 范数、评分差相对温度、发送上限梯度、未触及上下限的候选、重新进入支持的频率 | 非零导数与实际有效更新分别记录；固定温度也可能评分集中，无求根不保证上限梯度较小 |
| 记忆信用 | 写入到 Read／Full 的延迟、未来梯度、截断位置 | 保留写入提供未来通路，其实际使用需观测 |
| 节点分工 | 条件激活、总发送强度为正时的各节点占比 $c_v/\sum_u c_u$、输入类型、记忆检索，替换或打乱后的质量 | 稠密选择中仅看激活数量难以判断分工，仍需检查发送占比与内容互补；干预可能引起分布变化 |
| 全图工作 | Agg、KV 写入、Read、评分、增益、区域匹配、求解与反向、Full、消息、缓存 | 采用局部教材附录 S.4 及 HB 的候选公式；共享计算计一次 |
| 运行成本 | 训练、prefill、decode 分别计时，含教师与辅助分支 | 算术工作、累计时间和端到端时间分别报告 |
| 软硬差异 | 独立轨迹的消息、有效状态、读出和任务质量 | 满足定理条件的温度扫描与实际训练 checkpoint 分开解释 |

出现长期饱和时，先检查节点是否获得输入，以及是否有样本使它的发送强度进入上下限之间并获得梯度，再判断是否需要更高温度、较弱成本压力或额外暴露。更复杂的评分器可以增加判断信息，分配层的零 Jacobian 仍会阻断直接评分反馈。完全缺席的 HB 路径还依赖上游覆盖。

较强 selector 的当前增量成本与后续减少的工作分别计量。撤去唯一激活者时需另选替代，其邻域和后续选择都可能变化。局部 Full 数减少无法单独确定整图时间的变化。
