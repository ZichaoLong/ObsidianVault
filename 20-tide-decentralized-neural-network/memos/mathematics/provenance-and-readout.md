# 来源、聚合与读出

本文研究消息身份、输入来源和安全聚合，以及压缩后保持未来可观察行为的条件。原子、时间纤维、端口与完整切面沿用正典；保守外部依赖集合沿用分块教材，各节分别讨论来源构造与附加读出。

第 2 节判断压缩能否保持一个指定观察；第 3 节给出保持未来观察的逐步条件；第 4 节研究可能来源的保守记录；第 5 节说明输出观察的时间边界。这几项分别回答数值保持、状态继续、来源审计和读出可见性。

## 1. 消息身份、时间与输入来源

一条消息可能融合多个输入位置的影响。至少区分：

| 对象 | 回答的问题 |
| --- | --- |
| 消息标识符 | 这是哪一次发送产生的哪条记录？ |
| 逻辑时间 $\theta$ | 它在哪个时间纤维中参与处理？ |
| 输入来源集合 | 哪些外部输入可能影响它？ |
| 读出端口与时间 | 哪个可观察输出使用这个值？ |

三个层级的聚合输入都保留来源坐标；具体函数可以使用或忽略它。不能先丢掉来源，再假定未来还可以无成本恢复。

“属于 token $t$”通常只是应用层标签，不是一般消息的唯一数学归属。跨 token 融合后，强行指定唯一 owner 会丢失其他来源；也不能用这个标签代替逻辑时间排序。

## 2. 指定观察下的聚合条件

设完整输入对象属于集合 $X$，下游可观察结果由 $F:X\to Y$ 给出。要把输入压成 $\alpha:X\to Z$，充分且必要的条件是存在 $\bar F: \alpha(X)\to Y$，使

$$
F=\bar F\circ\alpha.
\tag{1}
$$

等价地，任意 $x,x'$ 若 $\alpha(x)=\alpha(x')$，就有 $F(x)=F(x')$。

**证明。** 有式 (1) 时，两者应用同一 $\bar F$ 得同值。反过来，对 $z\in\alpha(X)$ 任取满足 $\alpha(x)=z$ 的 $x$，令 $\bar F(z)=F(x)$；上述条件保证定义与选择无关。□

这个结论只回答指定观察函数 $F$。例如两条消息值为 $(1,2)$ 或 $(2,1)$，求和都为 3。若下游只读和，压缩安全；若下游问“第一来源是什么”，就不安全。

## 3. 保持未来观察的状态压缩

### 3.1 一步转移的相容条件

压缩有状态模型时，需要保持所选的未来观察。本节给出可以沿时间逐步检查的充分条件：给定一步转移 $T:X\times S\to Y\times S$、状态抽象 $\alpha:S\to Z$、输出抽象 $\beta:Y\to\bar Y$，以及抽象转移 $\bar T:X\times Z\to\bar Y\times Z$，对所有合法 $x,s$ 都有

$$
T(x,s)=(y,s')\quad\Rightarrow\quad
\bar T(x,\alpha(s))=(\beta(y),\alpha(s')),
\tag{2}
$$

从 $s$ 与 $\alpha(s)$ 出发，式 (2) 保证本步抽象输出相同、下一状态继续满足抽象关系。对输入长度归纳，压缩状态即可精确继续产生同一抽象观察。若要保持原输出本身，取 $\beta=\mathrm{id}_Y$。此为 transition 的商语义；它不承诺重建原状态。

### 3.2 表示、状态商与近似

1. **无损表示**：固定 Decode 恢复确切数学状态及每次计算快照。共享数组、不可变前缀视图可以属于此类；规范记录仍逐坐标相等。
2. **保持观察的状态商**：满足式 (2)，保留指定未来观察。例如去掉以后永远不可读的内容；原始状态可能无法恢复。
3. **近似压缩**：允许输出或状态误差，须给输入域、误差度量及跨步累积方式。
4. **蒸馏成另一模型**：通过数据拟合旧行为，质量由实验评估。

KV 序列与 SSM 状态分别由自身函数定义。带权 KV 的有效窗口投影属于指定观察的比较，固定规格的精确块求值则仍需恢复原始保存序列。具体删除与压缩的证据由实现维护；数学上须明确哪些差异在未来观察中保持不可见。

## 4. 保守的来源集合

保守外部依赖集合及其前缀检查采用[分块教材 §8.3](../../timed-dag-chunk-prefill-learning-note.md#83-自回归输出的结构检查)的定义。把外部记录标成 $(i,k)$，其中 $i$ 是输入端口，$k$ 是该端口位置。在固定有限切面的递归展开中，为值和存在性标记附加有限集合 $D$，使集合覆盖不同输入下的可能来源：

- 外部输入的集合包含自身 $(i,k)$。
- 常数和与数据无关的初态可取空集。
- 一个函数输出的集合可取全部自变量来源集合的并。
- 条件选择取条件与全部分支的来源并集，覆盖不同输入下可能选择的分支。
- 消息是否存在、节点是否成为候选也可能受输入影响。审计必须给这些存在性或缺失标记记录控制来源，不能只给实际到达的数值附加集合。

例如某输入 $x$ 决定一条消息是否发送，后继对实际收到的值求和。即使本次没有消息、和为零，零值也可能受 $x$ 控制；只对收到的数值取来源并集会漏掉它。在把值、选择和存在性依赖全部显式化之后，才能沿对应的有限作用依赖图归纳，得到保守的依赖集合。

这个集合未必最小：$x-x$ 的输出恒为零，简单并集仍会记录 $x$。若要声称“精确依赖”，须另定义函数对输入变化是否敏感，不能把传播得到的上界称为精确因果解释。

这样的集合满足分块教材的保守外部依赖定义；当它包含于任务允许的输入前缀时，就得到相应的自回归保证。多输入端口时，前缀按各端口可见的位置数声明。逻辑时间和正时延给出的切面因果性由正典递归自身保证。

## 5. 读出时间与未来上下文

在固定读出时间，参考语义应声明使用哪些端口记录，以及如何合并它们。实际完成慢，不允许补改已经定义的过去输出。

“等待本次所有声明分支汇合”与“较晚分支只影响未来上下文”是不同模型：前者有当前输出依赖，后者必须沿正时延消息进入未来事件。二者都不能用墙钟截止时间决定数学可见性。

TimedDAG 的不等长路径可以让多个输入位置在一个逻辑时间纤维中汇合。此时一个 Full 调用的输入是整个聚合结果，不能再把它任意拆成彼此独立的 token 子问题。若要训练自回归模型，还需声明 token 输入时间、读出时间及允许的因果前缀。
