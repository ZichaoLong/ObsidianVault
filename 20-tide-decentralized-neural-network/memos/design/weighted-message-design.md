# 带权消息架构的设计空间与取舍

本文从整体阅读局部架构：哪些信息被保存，哪些量参与评分与发送，哪些计算能省去，以及改变依赖可能得到什么、失去什么。共同定义见[局部架构](../../local-semantics/weighted-message/architecture-learning-note.md)，分配见[区域教材](../../local-semantics/weighted-message/region-allocation-learning-note.md)，记忆分别见 [KV](../../local-semantics/weighted-message/kv-memory-learning-note.md)、[基础循环](../../local-semantics/weighted-message/recurrent-memory/affine-delta-learning-note.md)、[Gated DeltaNet](../../local-semantics/weighted-message/recurrent-memory/gated-delta-learning-note.md)与 [SSD](../../local-semantics/weighted-message/recurrent-memory/ssd-learning-note.md)。

数学性质提供设计边界，机制分析提供选择理由，任务表现仍依赖完整模型与训练。一个值得保持的研究判断是：保留任务需要的内容与历史依赖，同时减少一个量兼任多个控制作用的情况。它可以随实验结果逐步加强、减弱或修改。复杂耦合、计算成本和失败配置可能使某些判断长期无法被独立检验；未检验不等于已证伪，也不等于已验证。

表中的能力对应已定义函数；优势与困难是由信息和导数结构作出的机制分析。整网性质的充分条件见[共同组合定理](../../local-semantics/weighted-message/architecture-learning-note.md#6-数值性质的组合)，各发送函数的适用范围见区域教材 §7—8。外部实验依据集中在第 8 节，具体比较与观测由研究问题文档负责。

## 1. 从整体看各个选择

先选择[全连接分层](../../topologies/fully-connected-layered.md)、[HB-Lattice](../../topologies/hb-lattice.md)或其他合法图，确定谁能向谁发送、何时汇合，以及哪些节点共同选择。固定一次区域作用，候选节点 $v$ 的旧状态为 $q_v$，接收聚合为 $(r_v^{\mathrm{in}},u_v)$；Upd 得到新状态 $\widetilde q_v$。全部候选保留这次更新，描述模式选择用于评分的状态：Read$^+$ 取新状态，Read$^-$ 取旧状态，Read$^0$ 取初态。

记忆模块从所选状态取得 Mem 四元组，并提供当前内容特征 $p_v(u_v)$。逐节点增益候选用这些量形成局部评分 $s_v^{\mathrm{loc}}$ 和发送增益 $\gamma_v$，以及区域 Attention 所需的特征。沿用区域教材的
$w_v=\min(1,(r_v^{\mathrm{in}})_+)$、$\mu_v=\min(1,\gamma_v(r_v^{\mathrm{in}})_+)$；$w_v$ 是截断接收量，$\mu_v$ 的上限或权重作用由发送函数决定。

两个区域控制候选改用固定最大倍率的节点上限 $\mu_v^{\max}=\min(1,\gamma_{\max}w_v)$。Describe 另提供内容与记忆的向量证据；区域汇集后产生共同阈值 $\eta_j$ 或实际总量 $B$，评分负责相对分配。它们共用约束求解，取舍见 §3.2。

下面按计算位置列出选择，各行说明所用输入和产生的输出。Full 使用新状态；评分所读的状态由描述模式确定。

| 计算位置 | 输入与输出 | 在此处选择什么 |
|---|---|---|
| 接收 Agg | 完整来源消息 $\to(r_v^{\mathrm{in}},u_v)$ | 区域共享、节点独立、来源独立或低秩适配；决定压缩前怎样处理来源差异 |
| 记忆 Upd | 旧状态、当前接收 $\to\widetilde q_v$ | KV、基础仿射、基础 Delta、Gated DeltaNet 或 SSD；决定保存的状态与更新规则 |
| 记忆描述 Mem | 指定状态、当前内容 $\to$ 两个描述向量与两个统计量 | 时间摘要（sum）、KV 内容检索（qry）或循环矩阵查询（state），具体通道见 §2.2 |
| 节点描述 Describe | 当前接收、特征、Mem $\to d_v$ | cat／match 形成局部评分；按发送候选提供节点增益相关量或区域控制证据；att 另提供匹配向量 |
| 区域评分 | 完整描述族 $\to(s_v)_v$ | 独立评分（ind）直接使用 $s_v^{\mathrm{loc}}$；区域 Attention 评分（att）加入共同 query 与各节点记忆 key 的匹配 |
| 区域控制 | 接收加权的描述证据 $\to\eta_j$ 或 $B$ | 固定／上下文阈值，或固定／上下文比例产生指定总量；只用于相应候选 |
| 发送分配 | 所需评分及接收相关量 $\to(c_v)_v$ | 约束分配、直接 Attention、固定总强度 Attention、总量缩放 Attention、按比例分配或硬选择 |
| 完整计算 Full | 新状态、当前内容、正发送强度 $c_v$ $\to$ 逐边与逐端口值族 | 所选模块计算内容 $G_v$，广播载荷 $(c_v,G_v)$，决定下游的接收 |

例如“KV＋时间摘要＋拼接评分＋独立评分＋二次正则约束分配”是一份组合。把时间摘要换为内容检索，改变 Mem 的取得方式；把独立评分换为区域 Attention 评分，要同时扩充 Describe 的输出与 SelStep 的输入；把约束分配换为直接 Attention，保留评分过程，改变评分到 $c_v$ 的函数。各替换的类型与数值性质分别按共同架构检查。

区域 Attention 的 query 汇集权重可选 $\mu_v$ 或 $w_v$。配置名 mu 对应前者，received 对应后者；在直接 Attention 的份额中使用这两个配置值时，也分别表示这两个量。它们对增益学习通路的影响见 §3。完整运行可对照[全连接的两次输入](../../instances/fully-connected-layered-weighted-message.md#2-两层图上的两次输入)与 [HB 的分叉汇合](../../instances/hb-lattice-weighted-message.md#2-三层图上的分叉汇合与记忆)。

## 2. 保存历史与分配信用

### 2.1 KV 与四种循环记忆

| 记忆 | 有利特性 | 限制与潜在困难 |
|---|---|---|
| KV | 当前 query 可以直接定位历史条目；旧条目保留各自身份；窗口与位置机制明确 | 存储与读取随有效条目数增长，有限窗口可限制这项增长；聚合及 K/V 投影已压缩信息，注意力也可能检索失败 |
| 基础仿射（affine） | 状态大小固定，输入决定系数，具有简单仿射复合 | 多条关联叠加可能干扰；基础绑定的表达与外部完整 SSM 有差别 |
| 基础 Delta（delta） | 预测误差驱动定向修正，便于理解和比较更新规则 | key 方向仍会干扰；仅有基础投影、门和读出 |
| Gated DeltaNet（gated_delta，简称 GDN） | 短卷积提取近期特征，L2 限制 Q/K 范数；保留门与定向误差修正共同管理历史 | 全候选执行卷积和矩阵更新；历史被压缩、覆盖，较 SSD 具有更复杂的转移结构 |
| SSD（ssd） | 每头标量转移适合专门分块算法；输入相关写入、读取与直通项提供不同通路 | 同一头的旧矩阵统一衰减；没有 Delta 的当前关联误差校正，步长同时控制遗忘和写入 |

Attention、SSM 与 Delta 都可从“怎样写入、保存和读取”来比较。结构化的状态更新、残差通路、并行算法、训练数据与数值设计共同影响结果；不能把这些模型相对一般 RNN 的表现归因于一个已经确定的原因。

KV 的历史条目允许直接匹配；循环模块通过当前矩阵读历史，过去的写入仍经过中间更新。仿射性便于重排求值，不自动保证长期梯度良好；状态压缩也可能提供有用归纳偏好。KV 保存的同样是节点接收到的聚合表示，不能由“逐条保存”推出原始输入可无损恢复。

GDN 沿用基础 Delta 的矩阵误差修正形式，另定义卷积特征、多头、具体门和输出变换；SSD 与基础仿射同样由旧矩阵的标量保留及当前外积写入组成，但写入系数、特征与读取有各自定义。对应关系在各教材的更新公式后说明。同一代数形式允许共用仿射复合依据，参数化和完整状态的差异仍会改变模型函数。

四种循环函数均有完整定义。外部原模型对应限于各教材附录列出的普通序列混合器、参数和开关；Tide 的接收权重、时间空档、辅助描述、区域分配及图结构仍需自己的训练依据。基础 Delta 与 GDN 可分别用于研究更新规则和包含卷积、门、输出变换的完整模块。

### 2.2 描述读取与 Full 读取

共同 Mem 接口返回 $(M_{\mathrm{short}},M_{\mathrm{long}},W_{\mathrm{short}},W_{\mathrm{long}})$。两个 $M$ 都有宽度 $d_s$，供相同的评分函数使用。下表每一行对应一份记忆描述绑定，两个向量按所选行一起取得；各教材先定义候选向量，再显式组装这个四元组。

| 记忆与描述方式 | $M_{\mathrm{short}}$ | $M_{\mathrm{long}}$ |
|---|---|---|
| KV 时间摘要 | 窗口内按短期衰减汇集的摘要 | 窗口内不作时间衰减的摘要 |
| KV 内容检索 | 当前 query 对短期加权条目的检索 | 当前 query 对窗口内条目的检索 |
| 各循环模块的时间摘要 | 独立保存的短期接收摘要 | 独立保存的累计接收摘要 |
| 基础循环的矩阵查询 | 查询具有短期被动衰减的矩阵 | 查询无被动衰减的矩阵 |
| GDN／SSD 的矩阵查询 | 短期接收摘要 | 当前内容对一组多头矩阵的查询 |

在基础循环中，两份矩阵仍各自受到输入相关保留门的作用；GDN／SSD 的 long 通道也受所选门与被动衰减影响。两个 $W$ 始终按各自的时间规则统计接收写入量。其通道名称和数值不能直接解释为矩阵中可恢复的历史长度。

KV 时间摘要已有独立的摘要投影；内容检索则共享 Full 的 K/V 后再投影。共享可让内容与控制使用共同证据，也让评分反馈改变 Full 记忆。独立的小型描述 K/V 是合理的进一步候选：减轻控制读取成本、减少两项任务的参数冲突，同时增加写入和状态。采用前需定义新增状态、写入、窗口、读取、比较投影与继续；当前教材没有把它列为已经完整绑定的配置。

Read$^-$ 已可用于“当前内容查询旧记忆”，而 Full 仍读取本次写入后的状态。它移除当前写入到当前评分的那条路径，可能减少自匹配，也可能丢失有助于选择的最新证据。默认 Read$^+$ 保留这种证据。两种描述模式都在当前逻辑时间查询，使用的状态快照不同；未来状态依赖仍然存在。

矩阵查询保留当前内容到关联记忆的直接读取通路，selector 在每个候选上支付查询成本。改用时间摘要可以省这次查询，同时改变评分可获得的证据。

### 2.3 时间、门与梯度通路

Gated DeltaNet 分开保留门、误差写入门和输出门；SSD 的有效步长 $d_h$ 同时作用于保留比例与写入系数，输出门另外定义。它们都与发送增益 $\gamma$ 和发送强度 $c$ 分开。记忆可以影响区域评分及增益，区域选择则通过未来消息改变后续写入，整网依赖仍然存在。

固定本次输入特征时，GDN 对旧矩阵的线性系数为 $g(I-\beta kk^\top)$，SSD 为 $gI$，还各乘被动衰减。两者在本文门范围内的范数至多为 $1$，所以这条固定输入的递归通路不会逐步放大范数；乘积仍可能很快衰减。完整训练还包含投影、卷积、门、区域选择及图反馈，不能由这一局部界推出总梯度稳定。稳定 L2 与 RMS 在很小分母附近也可有较大导数，归一化常数是数值定义的一部分。

GDN 与 SSD 的短卷积按固定逻辑时间取槽，并以 $w$ 写入历史；这是保证弱事件消失时历史位置不跳变的一种具体选择。从空缓存开始、单位接收且接收间隔等于抽头间距 $\delta_{\mathrm{conv}}$ 时，它恢复普通因果卷积，在稀疏 HB 中则保留空档。只对“最近收到的若干条消息”做卷积可能更适合按事件计的任务，但定义的距离不同，且不能直接使用当前连续性引理。稀疏节点也可能很少有历史落在固定抽头上，抽头数、抽头间距与图时间需要一起理解。

状态大小固定只描述存储规模。Tide 的全部正接收候选仍执行矩阵更新与短卷积；全连接层不会因本节点未激活而省去这些工作。HB 若让整次下游接收缺席，才同时省去相应 Upd。比较实际成本需计入投影、状态带宽、Read、Full、图消息和硬件利用率，不能仅比较 KV 缓存与矩阵的元素数。

## 3. 一个量承担哪些作用

### 3.1 逐节点增益

沿用第 1 节的 $w_v,\mu_v$，记 $M=\sum_{v\in C}\mu_v$，其中 $C$ 为本次区域候选集。直接 Attention 将评分归一化为份额 $p_v^{\mathrm{sel}}$，再取 $c_v=\mu_vp_v^{\mathrm{sel}}$；归一化所用的非负基权重可取 $\mu_v$ 或 $w_v$。下表固定当前接收、记忆特征和其他参数，只改变增益，比较它直接影响哪些量。表内省略节点下标。

| 组合 | 增益的直接作用 | 被保留或移除的学习通路 |
|---|---|---|
| query 按 $\mu$，直接 Attention 基权重为 $\mu$ | 改共同 query、改各节点评分、改份额、改本节点幅度 | 作用丰富，一个局部增益可影响区域内多个候选 |
| query 按 $w$，直接 Attention 基权重为 $\mu$ | 改份额及本节点幅度 | 移除增益经 query 改全部评分的通路 |
| query 按 $w$，直接 Attention 基权重为 $w$ | 通过本节点外乘 $\mu$ 改幅度 | 在当前局部求值中分开发送幅度与份额；失去增益协助竞争的能力 |
| query 按 $w$，约束分配 | 通过发送上限、可行域与下限影响分配 | $M>1$ 且节点上限局部松弛、正则不显含 $\mu$ 时，当前分配可能完全不依赖增益 |
| query 按 $w$，固定总强度且基权重为 $1$ | 无 | 增益可能整项不参与前向，应从该配置中省去 |
| 总量缩放 Attention | 通过 $M$ 和基权重 $\mu$ 改总量与份额 | 总量低时仍能按评分调配，保留接收与竞争的耦合 |

记忆影响增益和评分，区域共同决定实际发送；当前架构可学习记忆相关唤醒及节点分工。对“记忆决定唤醒、selector 决定分工”的更细分工，query 与份额都使用 $w$ 的直接 Attention 提供一份明确实现，但两个头仍共享输入证据与后续任务目标。

全连接单位输入实例逐节点 $w=\mu=1$，上述增益差别全部被截断；HB 的弱接收提供可辨别场景。减少依赖也可能使某项参数不再获得有效梯度，因此判断应同时看表达能力与反馈覆盖。

不采用隐式 stop-gradient 来声称前向已经解耦。停止某条反传改变指定反向规则；改变 query 或基权重才改变前向依赖，两者应分别定义。

### 3.2 区域阈值与指定总量

两者都表达区域共同调节发送、评分决定相对分工。定义见[区域分配 §3—4](../../local-semantics/weighted-message/region-allocation-learning-note.md#33-区域控制的共同输入)。相同的节点上限保护弱输入边界，相同的接收加权摘要提供区域内容与记忆证据；两者都只求一个总量乘子。

| 方面 | 区域阈值 | 指定总量 |
|---|---|---|
| 直接控制 | 从全部评分减去 $\eta_j$，总量由优化求得 | 给定 $B$，优化在该总量下分配 |
| 直接反馈 | 总量约束松弛时有作用；被上下界固定时共同平移可被抵消 | 总量有余量时，改变 $B$ 必然改变发送总和；分支导数见教材 §6.2 |
| 相对分配 | 绝对评分和阈值共同影响总量与分工 | 给定 $B$ 后共同评分平移无效，相对评分决定分配 |
| 零温目标 | 单位输入与评分条件下可收敛到配对单位强度硬选择 | 收敛到指定总量下的唯一线性最优分配，可有小数发送 |

直接总量的反馈路径便于解释，但任务边际影响相消、sigmoid 饱和和总量范围退化仍会抑制学习。自由节点只有一个时，评分对该次分配的直接导数可为零，而总量导数仍非零。区域阈值对整个区域提供同一偏移；同时平移所有评分和阈值保持分配，参数的数值大小须结合这项自由度解释。

两者的下界为 $b^{\mathrm{recv}}=\min(1,\sum w_v)$，固定阈值候选 constrained 使用 $\min(1,\sum\mu_v)$。前者允许放大上限提高而最低发送保持。比较完整训练时，要把这项下界差异与控制头的区别分别记录；两个区域候选之间可在相同上限和下界下比较。总量头可以在较低总量下调节，但当节点上限之和等于下界时仍无余量。

全连接单位输入保持 $w=\mu^{\max}=1$；若 $k>1$，两个区域头仍可能影响结果。若 $k=1$，总量被固定为 $1$，两个头均无调整空间。HB 可出现弱节点接收，具体余量和反馈按该次运行判断。一般弱总接收时，即使 $k=1$，两个区域候选也可能有非退化的总量区间。

正温度稀疏性与零温目标分别选择。两个候选均可使用 quad 或广义熵产生精确零，也可使用 Shannon／bern 持续混合。较低温度仍可能带来较大的过渡区斜率和较宽的饱和区；区域头没有消除这些性质。输入连续、局部梯度存在与训练效果良好是三项不同判断。目前没有训练结果说明哪一种区域控制更优。

## 4. 评分信息与分工

局部评分先把当前内容、记忆描述和接收统计变为标量 $s_v^{\mathrm{loc}}$。两个候选具有相同的输入来源与输出类型：

| 局部评分 | 有利特性 | 限制与风险 |
|---|---|---|
| 拼接评分 | 小型单隐藏层网络，已含统计量与内容—记忆乘积 | 可能利用记忆长度或接收频率等捷径；各信息的尺度和用途需辨明 |
| 分组匹配评分 | 分组非线性、归一化及显式匹配，使各类证据的处理较清楚 | 相似度仍需映到执行价值；乘性交互和归一化都有优化取舍 |

区域评分随后决定如何使用局部评分。独立评分令 $s_v=s_v^{\mathrm{loc}}$；区域 Attention 评分另形成共同 query，与节点记忆 key 匹配，再和局部评分按指定尺度合成 $s_v$。

| 区域评分 | 有利特性 | 限制与风险 |
|---|---|---|
| 独立评分 | 描述小、准备较少；后续约束分配或归一化仍引入区域竞争 | 本地内容压成标量后，跨候选的关系表达有限 |
| 区域 Attention 评分 | 当前区域内容形成 query，比较各节点记忆；零发送但正接收者仍可影响共同 query | 单 query 有信息压缩，控制更耦合；未执行 Full 的具体反事实结果仍不可见 |

两种局部评分均可接入两种区域评分。更换区域评分时，节点描述随之增减当前特征与记忆 key；发送函数继续接收同型的最终评分族。

参数或私有状态的名字本身不产生分工。相同输入、参数和历史可保持对称；全连接同层通常更依赖私有投影与初始化差异，HB 的邻域已提供不同输入，同时可能导致暴露不均。

还可考虑将增益头的统计输入与内容匹配分开，显式规定 Q/K 归一化和匹配尺度，或在 Agg 压缩前保留多个来源摘要。这些方向有明确动机，但会改变函数、参数或本地内容空间；应在选定后再补完整定义，避免把概念列表当成可直接运行的组合。

## 5. 发送规则的取舍

发送函数使用接收相关量及所需评分，产生控制 $c_v$；正分量对应本次激活节点。约束优化先选固定阈值、区域阈值或指定总量，再选择正则；下表的约束行比较正则本身，区域控制的区别见 §3.2。Attention 规则共用归一化份额，分别定义如何变为发送强度。按比例分配不使用评分，硬选择单独给出激活集合。完整函数与性质见[区域分配教材](../../local-semantics/weighted-message/region-allocation-learning-note.md#45-完成区域返回与性质对照)。

| 方法组 | 候选 | 有利特性 | 风险与成本 |
|---|---|---|---|
| 约束优化 | 约束 Shannon | 保持每节点上限和区域总量保障，持续混合 | 一般需求标量乘子；上限和总和约束可使评分反馈消失；执行全部有效 Full |
| 约束优化 | 二次正则约束分配 | 正温度精确零，过渡区斜率清楚，可省 Full 及下游工作 | 零或上限区直接评分反馈消失；低温过渡区陡峭 |
| 约束优化 | 广义熵约束分配，$1<\alpha<2$ | 精确零且接近零时响应更平缓 | 弱分量的恢复反馈也可能更弱；仍有截断与低温问题 |
| 约束优化 | 二元熵约束分配 | 非单点约束下有效候选在上下限之间，保留直接分配通路 | 全有效 Full 参与；极端占用比例的梯度仍小 |
| Attention 份额 | 直接 Attention | 无求根，保留每节点发送上限与弱输入连续性；可分开发送增益和份额依据 | 全有效 Full 参与；总强度可能逐层减小，微弱候选的反馈也可能很弱 |
| Attention 份额 | 固定总强度 Attention | 无求根，持续混合多个节点；弱线索可凭记忆获得较大份额；低总量仍有评分反馈 | 全部支持节点执行 Full；弱线索与噪声都可能触发单位总量，零输入边界按独立规则处理 |
| Attention 份额 | 总量缩放 Attention | 无求根，全区域趋弱时总发送趋零；低总量仍能依评分调配 | 可让单节点超过自身 $\mu$，放大某个弱来源；没有现成的整网硬化结论 |
| 按比例 | 按比例分配 | 保留发送上限与区域总量，提供不依赖评分的完整参照 | 全有效 Full 参与，分配本身不给评分网络反馈 |
| 硬选择 | 硬选择 | 每次严格限制激活数，工作上限明确 | 成员排序在严格间隔内局部不变，需要另行处理训练反馈与探索 |

稠密激活也可以形成内容与发送份额的分工，精确稀疏增加了跳过计算的能力。正控制量、非零局部导数和有效任务更新分别观察。更多信息的 selector 可能以当前准备换取更有价值的后续计算；总收益取决于消息出度、邻域重叠和任务。

对全区域 quad 或固定 $\alpha>1$ 的 ent，区域教材 §7.4—7.6 分别给出相应条件下的正温度精确性。固定阈值与区域阈值比较单位输入的配对硬运行；指定总量比较自身的唯一线性最优运行。所需温度依赖固定模型、输入和有限时间范围；训练改变参数，条件也会改变。固定温度、有限降温与零温部署的选择仍取决于计算量、反馈覆盖及任务表现。

共享 query 使这些函数都可具有跨候选依赖。固定上限与 keys 时，quad 对 query 是分段仿射，softmax 对 query 光滑；全网络的参数训练通常均非凸。这些局部性质不能排列整体“非凸程度”或训练难度。

## 6. 弱接收、触发与传播

“达到条件后发出较强内容”可以通过有界增益、记忆检索与区域分配共同表达。当前规则没有单独的膜电位、放电阈值与复位状态；KV 影响评分或增益并不自动等同于这套特定动力学。若任务需要静默积累、阈值触发和复位，可以另定义含这些状态的 Upd／Read／Next；需明确接收和无输入时的行为。

区域教材 §8.2 中满足发送上限的有界增益发送，允许弱信号沿有限路径变强，同时保持零边界连续性。任意微小正输入立即归一化成单位发送则会破坏该边界。把 $\mu$ 除以 $\min(1,M)$ 会在 $0<M<1$ 时得到和为 $1$ 的上限族；若继续要求总发送至少为 $1$，所有新上限会被用满，接收整体趋零时仍发送一个单位。这与明确的阈值触发、历史积累有不同含义。

约束分配的下限同时提供非空与区域总量保障。固定阈值候选在低上限总量处强制使用全部上限；两个区域候选按接收取下界，各自的退化情形见区域教材 §4.1。较大总量与较小节点上限可共同要求很多节点激活，单靠降温无法突破这个可行性限制。$b=\max\mu$ 或 $b=\min(1,M/2)$ 等其他下界未作为完整配置纳入教材；采用时须重新给出可行域、反向、传播与极限。

广播总强度还乘入出度。一个区域的强度范围合理，无法单独保证各下游都收到足量输入，更无法确定消息数或内容范数。实例中的传播定理使用了额外的连接覆盖条件。

## 7. 状态、拓扑与可判断的范围

默认接收驱动写入、全部候选保留更新、Next 不读取 Full、区域历史为单点，已经使若干依赖清楚分开。这些约定保留未来反馈机会；未来是否读取、是否在反向截断内使用，以及上游是否持续提供输入，仍决定实际信用。

固定图上的选择改变当前计算路径，空间边在其他输入和历史中仍可用。全连接层中所有节点继续准备；HB 可因上游不发送而省去整组下游作用。收拢会缩短某些路径的分离时间，可能有利于纠正早期选择，也可能稀释局部差异。

记忆的保存与读取、Full 的内容变换分别承担职责。KV 教材的读取残差尺度为零时，Full 只用当前内容及前馈残差，描述读取仍可使用 KV；删除写入或改变 Attention／FFN 排列则需要完整的新函数绑定。不同区域怎样搭配这些计算，应按任务依赖与总成本选择。外部架构提供可行例证，不能单凭相似排列推出 Tide 广播与选择更优。

研究记录可以写“当前更倾向某组合，依据是这些可观察结果，尚有这些替代解释”。不必为每个直觉预设一整套隔离实验。需要安排具体实验时，另查[可选研究问题与对照](../training/weighted-message-research-questions.md)，优先级由研究者结合整体掌握和资源决定。

GDN 的部件消融采用 $400$M 参数、同一 FineWeb-Edu 子集的 $15$B token。头宽 $128$ 的完整模型平均困惑度为 $27.35$，去短卷积为 $28.95$，去输出门为 $29.12$；平均常识准确率分别为 $47.26,46.16,45.46$。这支持把这些部件纳入一个可核对的完整候选，也显示基础 Delta 公式不足以承接原模型的效果声明。

同一论文的真实检索任务中，纯循环模型仍有相对 Transformer 的差距，加入滑窗 Attention 的混合模型改善部分结果。其吞吐比较也显示短序列上的 FlashAttention-2 Transformer 可有优势。故 KV、GDN、SSD 及按区域混合都有保留理由；长期检索、推理状态和训练吞吐的取舍由任务与完整实现决定。仓库的[位置、注意力与记忆调查](../../../30-technical-notes/attention-position-memory.md)汇集更广泛的结构和研究比较。

外部结果、数学命题、机制直觉与 Tide 的实测结果分别记录。当前文档不声明已有 Tide 训练质量或下游性能验证。
