# 带权消息架构的设计空间与取舍

本文从整体阅读局部架构：哪些信息被保存，哪些量参与评分与发送，哪些计算能省去，以及改变依赖可能得到什么、失去什么。共同定义见[局部架构](../../local-semantics/weighted-message/architecture-learning-note.md)，分配见[区域教材](../../local-semantics/weighted-message/region-allocation-learning-note.md)，记忆分别见 [KV](../../local-semantics/weighted-message/kv-memory-learning-note.md)、[基础循环](../../local-semantics/weighted-message/recurrent-memory-learning-note.md)、[Gated DeltaNet](../../local-semantics/weighted-message/gated-delta-memory-learning-note.md)与 [SSD](../../local-semantics/weighted-message/ssd-memory-learning-note.md)。

数学性质提供设计边界，机制分析提供选择理由，任务表现仍依赖完整模型与训练。一个值得保持的研究判断是：保留任务需要的内容与历史依赖，同时减少一个量兼任多个控制作用的情况。它可以随实验结果逐步加强、减弱或修改。复杂耦合、计算成本和失败配置可能使某些判断长期无法被独立检验；未检验不等于已证伪，也不等于已验证。

表中的能力对应已定义函数；优势与困难是由信息和导数结构作出的机制分析。整网数学保证集中在[共同组合定理](../../local-semantics/weighted-message/architecture-learning-note.md#6-数值性质的组合)，外部实验依据集中在第 8 节，具体比较与观测由研究问题文档负责。

## 1. 从整体看各个选择

| 问题 | 已定义的选择 | 表达的能力与主要代价 |
|---|---|---|
| 接收怎样压缩 | 区域共享、节点独立、来源独立、低秩适配 Agg | 共享减少参数；私有投影可在压缩前保留不同信息，所有候选支付准备成本 |
| 历史怎样保存 | KV；基础 affine／delta；完整 gated_delta／ssd | KV 保留逐条内容供检索；循环状态固定大小，完整候选另含短卷积、具体门与输出变换 |
| 评分看什么记忆 | KV 的 sum／qry；循环的 sum／state | 摘要便宜，当前内容检索更有针对性；state 的具体查询由模块定义，检索在候选上执行 |
| 本次写入是否参与评分 | Read$^+$／Read$^-$／Read$^0$ | 新状态包含当前证据；旧状态便于表达当前输入查询历史；当前模式不使用历史描述 |
| 怎样形成评分 | cat／match，ind／att | 紧凑标量、显式匹配和区域共享信息有不同成本与偏好 |
| 记忆怎样影响发送幅度 | 固定或上下文增益 | 可以唤醒强旧记忆，也可能放大噪声；截断会造成增益无效区 |
| 怎样汇集区域 query | 按 $\mu$ 或截断接收量 $w$ | 前者让发送能力参与共同判断；后者移除增益到共同 query 的直接依赖 |
| 怎样分配发送 | 约束分配、直接 Attention、固定总强度 Attention、区域总量分配、按比例分配、硬选择 | 分别选择发送上限、区域总量、稀疏性与梯度结构 |
| Full 怎样变换内容 | 历史读取加前馈残差；KV 可令读取残差尺度为零 | 读出后的变换与保存历史分别声明，去掉 Full 的历史读取仍可能保留 Read 对记忆的使用 |
| 怎样连接计算 | [全连接分层](../../topologies/fully-connected-layered.md)、[HB-Lattice](../../topologies/hb-lattice.md)、多区域与正时延反馈 | 决定可达信息、汇合时间、广播覆盖和实际工作 |

这些选择先按共同架构的类型与时间定义组成模型，再按各命题检查所需性质。固定总强度 Attention 的稠密组合、具有弱输入连续性的组合、以及满足软硬极限条件的组合各有用途。实际求值成本还取决于完整驱动输入何时可得及所采用的联合算法。

## 2. 保存历史与分配信用

### 2.1 KV、基础循环与完整候选

| 记忆 | 有利特性 | 限制与潜在困难 |
|---|---|---|
| KV | 当前 query 可以直接定位历史条目；旧条目保留各自身份；窗口与位置机制明确 | 存储与读取随有效条目数增长，有限窗口可限制这项增长；聚合及 K/V 投影已压缩信息，注意力也可能检索失败 |
| affine | 状态大小固定，输入决定系数，具有简单仿射复合 | 多条关联叠加可能干扰；基础绑定的表达与外部完整 SSM 有差别 |
| delta | 预测误差驱动定向修正，便于理解和比较更新规则 | key 方向仍会干扰；仅有基础投影、门和读出，缺少完整 GDN 的局部特征组合 |
| gated_delta | 短卷积提取近期特征，L2 限制 Q/K 范数；保留门与定向误差修正共同管理历史 | 全候选执行卷积和矩阵更新；历史被压缩、覆盖，较 SSD 具有更复杂的转移结构 |
| ssd | 每头标量转移适合专门分块算法；输入相关写入、读取与直通项提供不同通路 | 同一头的旧矩阵统一衰减；没有 Delta 的当前关联误差校正，步长同时控制遗忘和写入 |

Attention、SSM 与 Delta 都可从“怎样写入、保存和读取”来比较。结构化的状态更新、残差通路、并行算法、训练数据与数值设计共同影响结果；不能把这些模型相对一般 RNN 的表现归因于一个已经确定的原因。

KV 的历史条目允许直接匹配；循环模块通过当前矩阵读历史，过去的写入仍经过中间更新。仿射性便于重排求值，不自动保证长期梯度良好；状态压缩也可能提供有用归纳偏好。KV 保存的同样是节点接收到的聚合表示，不能由“逐条保存”推出原始输入可无损恢复。

四种循环函数均有完整定义。外部原模型对应限于新教材附录列出的普通序列混合器、参数和开关；Tide 的接收权重、时间空档、辅助描述、区域分配及图结构仍需自己的训练依据。基础 delta 与完整 gated_delta 可分别回答“更新规则有什么作用”和“完整模块是否值得采用”。

### 2.2 描述读取与 Full 读取

KV sum 已有独立的摘要投影；qry 则共享 Full 的 K/V 后再投影。共享可让内容与控制使用共同证据，也让评分反馈改变 Full 记忆。独立的小型描述 K/V 是合理的进一步候选：减轻控制读取成本、减少两项任务的参数冲突，同时增加写入和状态。采用前需定义新增状态、写入、窗口、读取、比较投影与继续；当前教材没有把它列为已经完整绑定的配置。

Read$^-$ 已可用于“当前内容查询旧记忆”，而 Full 仍读取本次写入后的状态。它移除当前写入到当前评分的那条路径，可能减少自匹配，也可能丢失有助于选择的最新证据。默认 Read$^+$ 保留这种证据。仅改变读取时刻不会消除未来状态依赖。

Gated DeltaNet 与 SSD 的 state 描述提供“短期接收摘要＋当前内容查询矩阵”。这保留 query 到已有记忆的直接读取通路，selector 仍须在每个候选上支付查询成本。sum 可以省这次矩阵查询，但不再提供内容相关的关联证据。辅助 $W_{\mathrm{long}}$ 只计接收写入量，较大的值不说明矩阵仍保存了更多可用历史。

### 2.3 时间、门与梯度通路

Gated DeltaNet 分开保留门、误差写入门和输出门；SSD 的输入步长同时作用于保留比例与写入系数，输出门另外定义。它们都与发送增益 $\gamma$ 和控制 $c$ 分开。记忆可以影响区域评分及增益，区域选择则通过未来消息改变后续写入，整网依赖仍然存在。

固定本次输入特征时，GDN 对旧矩阵的线性系数为 $g(I-\beta kk^\top)$，SSD 为 $gI$，还各乘被动衰减。两者在本文门范围内的范数至多为 $1$，所以这条固定输入的递归通路不会逐步放大范数；乘积仍可能很快衰减。完整训练还包含投影、卷积、门、区域选择及图反馈，不能由这一局部界推出总梯度稳定。稳定 L2 与 RMS 在很小分母附近也可有较大导数，归一化常数是数值定义的一部分。

新候选的短卷积按固定逻辑时间取槽，并以 $w$ 写入历史；这是保证弱事件消失时历史位置不跳变的一种具体选择。它在等间隔单位接收时恢复普通因果卷积，在稀疏 HB 中则保留空档。只对“最近收到的若干条消息”做卷积可能更适合按事件计的任务，但定义的距离不同，且不能直接使用当前连续性引理。稀疏节点也可能很少有历史落在固定抽头上，卷积长度、步长与图时间需要一起理解。

状态大小固定只描述存储规模。Tide 的全部正接收候选仍执行矩阵更新与短卷积；全连接层不会因本节点未激活而省去这些工作。HB 若让整次下游接收缺席，才同时省去相应 Upd。比较实际成本需计入投影、状态带宽、Read、Full、图消息和硬件利用率，不能仅比较 KV 缓存与矩阵的元素数。

## 3. 一个量承担哪些作用

令 $w=\min(1,(r^{\mathrm{in}})_+)$、$\mu=\min(1,\gamma (r^{\mathrm{in}})_+)$。以下表格均在固定当前接收、记忆特征和其他参数时讨论直接依赖；整网未来仍会耦合。

| 组合 | 增益的直接作用 | 被保留或移除的学习通路 |
|---|---|---|
| query 按 $\mu$，直接 Attention 基权重为 $\mu$ | 改共同 query、改各节点评分、改份额、改本节点幅度 | 作用丰富，一个局部增益可影响区域内多个候选 |
| query 按 $w$，直接 Attention 基权重为 $\mu$ | 改份额及本节点幅度 | 移除增益经 query 改全部评分的通路 |
| query 按 $w$，直接 Attention 基权重为 $w$ | 通过本节点外乘 $\mu$ 改幅度 | 在当前局部求值中分开发送幅度与份额；失去增益协助竞争的能力 |
| query 按 $w$，约束 quad／ent | 通过发送上限、可行域与下限影响分配 | $M>1$ 且上限局部松弛时，当前分配可能完全不依赖增益 |
| query 按 $w$，固定总强度且基权重为 $1$ | 无 | 增益可能整项不参与前向，应从该配置中省去 |
| 区域总量分配 | 通过 $M$ 和基权重 $\mu$ 改总量与份额 | 总量低时仍能按评分调配，保留接收与竞争的耦合 |

记忆影响增益和评分，区域共同决定实际发送；当前架构可学习记忆相关唤醒及节点分工。对“记忆决定唤醒、selector 决定分工”的更细分工，query 与份额都使用 $w$ 的直接 Attention 提供一份明确实现，但两个头仍共享输入证据与后续任务目标。

全连接单位输入实例逐节点 $w=\mu=1$，上述增益差别全部被截断；HB 的弱接收提供可辨别场景。减少依赖也可能使某项参数不再获得有效梯度，因此判断应同时看表达能力与反馈覆盖。

不采用隐式 stop-gradient 来声称前向已经解耦。停止某条反传改变指定反向规则；改变 query 或基权重才改变前向依赖，两者应分别定义。

## 4. 评分信息与分工

| 选择 | 有利特性 | 限制与风险 |
|---|---|---|
| cat | 小型单隐藏层网络，已含统计量与内容—记忆乘积 | 可能利用记忆长度或接收频率等捷径；各信息的尺度和用途需辨明 |
| match | 分组非线性、归一化及显式匹配，使各类证据的处理较清楚 | 相似度仍需映到执行价值；乘性交互和归一化都有优化取舍 |
| ind | 描述小、准备较少；约束分配或归一化仍引入区域竞争 | 本地内容压成标量后，跨候选的关系表达有限 |
| att | 当前区域内容形成 query，比较各节点记忆；零发送但正接收者仍可影响共同 query | 单 query 有信息压缩，控制更耦合；未执行 Full 的具体反事实结果仍不可见 |

参数或私有状态的名字本身不产生分工。相同输入、参数和历史可保持对称；全连接同层通常更依赖私有投影与初始化差异，HB 的邻域已提供不同输入，同时可能导致暴露不均。

还可考虑将增益头的统计输入与内容匹配分开，显式规定 Q/K 归一化和匹配尺度，或在 Agg 压缩前保留多个来源摘要。这些方向有明确动机，但会改变函数、参数或本地内容空间；应在选定后再补完整定义，避免把概念列表当成可直接运行的组合。

## 5. 发送规则的取舍

完整约束、支持与导数集中在[区域分配教材](../../local-semantics/weighted-message/region-allocation-learning-note.md#28-参数与性质对照)。下面比较研究上的用途。

| 候选 | 有利特性 | 风险与成本 |
|---|---|---|
| 固定总强度 Attention | 无求根，持续混合多个节点；弱线索可凭记忆获得较大份额；低总量仍有评分反馈 | 全部支持节点执行 Full；弱线索与噪声都可能触发单位总量，零输入边界按独立规则处理 |
| 直接 Attention | 无求根，保留每节点发送上限与弱输入连续性；可分开发送增益和份额依据 | 全有效 Full 参与；总强度可能逐层减小，微弱候选的反馈也可能很弱 |
| 区域总量分配 | 无求根，全区域趋弱时总发送趋零；低总量仍能依评分调配 | 可让单节点超过自身 $\mu$，放大某个弱来源；没有现成的整网硬化结论 |
| 约束 Shannon | 保持每节点上限和区域总量保障，持续混合 | 一般需求标量乘子；上限和总和约束可使评分反馈消失；执行全部有效 Full |
| quad | 正温度精确零，过渡区斜率清楚，可省 Full 及下游工作 | 零或上限区直接评分反馈消失；低温过渡区陡峭 |
| ent，$1<\alpha<2$ | 精确零且接近零时响应更平缓 | 弱分量的恢复反馈也可能更弱；仍有截断与低温问题 |
| bern | 非单点约束下有效候选在上下限之间，保留直接分配通路 | 全有效 Full 参与；极端占用比例的梯度仍小 |
| 按比例分配 | 保留发送上限与区域总量，提供不依赖评分的完整参照 | 全有效 Full 参与，分配本身不给评分网络反馈 |
| 硬选择 | 每次严格限制激活数，工作上限明确 | 成员排序在严格间隔内局部不变，需要另行处理训练反馈与探索 |

稠密激活也可以形成内容与发送份额的分工，精确稀疏增加了跳过计算的能力。正控制量、非零局部导数和有效任务更新分别观察。更多信息的 selector 可能以当前准备换取更有价值的后续计算；总收益取决于消息出度、邻域重叠和任务。

对全区域 quad 或固定 $\alpha>1$ 的 ent，共同架构 §6.3 还给出充分小正温度下的整网精确硬化：固定模型和有限输入在评分条件下可以已经进入与硬运行相同的函数分支。所需温度取决于沿途评分间隔；训练改变参数，间隔也会改变。该结论提供可核对的数学关系，固定温度、有限降温与硬部署的选择仍取决于计算量、反馈覆盖及任务表现。

共享 query 使这些函数都可具有跨候选依赖。固定上限与 keys 时，quad 对 query 是分段仿射，softmax 对 query 光滑；全网络的参数训练通常均非凸。这些局部性质不能排列整体“非凸程度”或训练难度。

## 6. 弱接收、触发与传播

“达到条件后发出较强内容”可以通过有界增益、记忆检索与区域分配共同表达。当前规则没有单独的膜电位、放电阈值与复位状态；KV 影响评分或增益并不自动等同于这套特定动力学。若任务需要静默积累、阈值触发和复位，可以另定义含这些状态的 Upd／Read／Next；需明确接收和无输入时的行为。

满足共同架构 §6 条件的有界增益发送，允许弱信号沿有限路径变强，同时保持零边界连续性。任意微小正输入立即归一化成单位发送则会破坏该边界。把 $\mu$ 除以 $\min(1,M)$ 会在 $0<M<1$ 时得到和为 $1$ 的上限族；若继续要求总发送至少为 $1$，所有新上限会被用满，接收整体趋零时仍发送一个单位。这与明确的阈值触发、历史积累有不同含义。

约束分配的下限同时提供非空与区域总量保障。它在低总量下限制评分的调配余地，见区域教材 §2.1。$b=\max\mu$ 是可研究的较弱下限，固定某些 $0<\mu_v<1$ 时仍不保证收敛到原硬选择；$b=\min(1,M/2)$ 甚至改变单位单候选的端点。这些修改目前未作为完整配置纳入教材；采用时须重新给出可行域、反向、传播与极限。

广播总强度还乘入出度。一个区域的强度范围合理，无法单独保证各下游都收到足量输入，更无法确定消息数或内容范数。实例中的传播定理使用了额外的连接覆盖条件。

## 7. 状态、拓扑与可判断的范围

默认接收驱动写入、全部候选保留更新、Next 不读取 Full、区域历史为单点，已经使若干依赖清楚分开。这些约定保留未来反馈机会；未来是否读取、是否在反向截断内使用，以及上游是否持续提供输入，仍决定实际信用。

固定图上的选择改变当前计算路径，空间边在其他输入和历史中仍可用。全连接层中所有节点继续准备；HB 可因上游不发送而省去整组下游作用。收拢会缩短某些路径的分离时间，可能有利于纠正早期选择，也可能稀释局部差异。

记忆的保存与读取、Full 的内容变换分别承担职责。KV 教材的读取残差尺度为零时，Full 只用当前内容及前馈残差，描述读取仍可使用 KV；删除写入或改变 Attention／FFN 排列则需要完整的新函数绑定。不同区域怎样搭配这些计算，应按任务依赖与总成本选择。外部架构提供可行例证，不能单凭相似排列推出 Tide 广播与选择更优。

研究记录可以写“当前更倾向某组合，依据是这些可观察结果，尚有这些替代解释”。不必为每个直觉预设一整套隔离实验。需要安排具体实验时，另查[可选研究问题与对照](../training/weighted-message-research-questions.md)，优先级由研究者结合整体掌握和资源决定。

## 8. 外部证据

| 来源 | 研究结果 | 对本设计的启发与边界 |
|---|---|---|

| [Peters et al., 2019，Sparse Sequence-to-Sequence Models](https://aclanthology.org/P19-1146/) | 定义连接 softmax 与 sparsemax 的 entmax，在形态变化与机器翻译任务中报告收益 | 支持比较正则形状；每个候选的发送上限与总和区间由本文自己的定义处理 |

| [Amos & Kolter, 2017，OptNet](https://proceedings.mlr.press/v70/amos17a.html) | 通过最优性条件对优化层隐式微分 | 支持优化层的反向方法；本文标量求根和导数由自身目标推导 |
| [Jang et al., 2017，Gumbel-Softmax](https://arxiv.org/abs/1611.01144) | 低温更接近离散采样，同时提高梯度方差；采用降至非零温度的方案 | 提供连续松弛与温度取舍证据；随机单纯形采样与本文确定性预算不同 |
| [Maddison et al., 2017，Concrete](https://arxiv.org/abs/1611.00712) | 连续松弛可优化离散随机图；作者在所做实验中未发现退火或自动调温很重要 | 支持保留固定正温对照，避免把退火设为普遍必需 |
| [Hazimeh et al., 2021，DSelect-k](https://arxiv.org/abs/2106.03760) | 平滑稀疏门控在所测多任务问题中具有竞争力；强调避免初始饱和造成零梯度 | 支持检验早期反馈与硬化的取舍；二进制编码和正则机制不同 |
| [Fedus et al., Switch Transformers](https://arxiv.org/abs/2101.03961) | Top-1 专家选择可有效训练，采用选择性高精度、初始化与辅助机制 | 提供硬成员选择的正面证据；其选中 softmax 权重与辅助信号不同于本文硬 $c=\mu$ |
| [Zoph et al., 2022，ST-MoE](https://arxiv.org/abs/2202.08906) | router z-loss 改善稳定性；更紧更新裁剪及部分噪声方案存在质量代价 | 稳定性干预需同时评价质量，具体损失与模型条件不能直接移植结论 |

循环记忆的主要证据及适用范围如下。

| 来源 | 可以据此判断的内容 | 转用边界 |
|---|---|---|
| [Mamba](https://arxiv.org/abs/2312.00752) | 输入相关的状态选择与专门扫描算法组成可训练的序列架构 | SSM 的成功依赖完整模块与实现，不能只据标量递归推断质量 |
| [Mamba-2](https://arxiv.org/abs/2405.21060) | 标量转移的结构化矩阵联系支持高效 SSD 分块求值，论文报告相应模型与性能结果 | 本文 ssd 具体对照 Mamba2Simple；不等间隔、带权输入与图消息仍需匹配实现 |
| [Gated DeltaNet §4、附录 B.2](https://arxiv.org/html/2412.06464v2) | 保留门与 Delta 结合在其多项任务中优于所比 Mamba2／DeltaNet；短卷积、输出门有实测贡献 | 原模型包含完整 block、训练数据和配方，收益不能逐项直接搬到 Tide |

GDN 的部件消融采用 $400$M 参数、同一 FineWeb-Edu 子集的 $15$B token。头宽 $128$ 的完整模型平均困惑度为 $27.35$，去短卷积为 $28.95$，去输出门为 $29.12$；平均常识准确率分别为 $47.26,46.16,45.46$。这支持把这些部件纳入一个可核对的完整候选，也显示基础 Delta 公式不足以承接原模型的效果声明。

同一论文的真实检索任务中，纯循环模型仍有相对 Transformer 的差距，加入滑窗 Attention 的混合模型改善部分结果。其吞吐比较也显示短序列上的 FlashAttention-2 Transformer 可有优势。故 KV、GDN、SSD 及按区域混合都有保留理由；长期检索、推理状态和训练吞吐的取舍由任务与完整实现决定。仓库的[位置、注意力与记忆调查](../../../30-technical-notes/attention-position-memory.md)汇集更广泛的结构和研究比较。

外部结果、数学命题、机制直觉与 Tide 的实测结果分别记录。当前文档不声明已有 Tide 训练质量或下游性能验证。
